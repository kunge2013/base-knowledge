### 第1步：创建目录结构

在你电脑上创建以下文件夹和文件：

text

test-project/
├── CLAUDE.md
├── CLAUDE.local.md
└── foo/
    ├── CLAUDE.md
    ├── CLAUDE.local.md
    └── bar/
        └── (空文件夹，用来发起对话)

---

### 第2步：写入不同内容

|文件|写入内容|
|---|---|
|`/test-project/CLAUDE.md`|"请回答：项目根目录的CLAUDE.md说——包管理器用 **npm**"|
|`/test-project/CLAUDE.local.md`|"请回答：项目根目录的CLAUDE.local.md说——包管理器用 **yarn**"|
|`/test-project/foo/CLAUDE.md`|"请回答：foo目录的CLAUDE.md说——包管理器用 **cnpm**"|
|`/test-project/foo/CLAUDE.local.md`|"请回答：foo目录的CLAUDE.local.md说——包管理器用 **pnpm**"|

---

### 第3步：在 `foo/bar/` 下发起对话

在 Claude 对话框里（工作目录设为 `test-project/foo/bar/`）问：

> "根据我的配置文件，我该用什么包管理器？"

---

### 第4步：预期结果

如果优先级机制正常，Claude 应该回答：

> **pnpm**

因为它读取顺序是：

text

1. /CLAUDE.md        → npm
2. /CLAUDE.local.md  → yarn（覆盖npm）
3. /foo/CLAUDE.md    → cnpm（覆盖yarn）
4. /foo/CLAUDE.local.md → pnpm（覆盖cnpm，最终生效）

---

## 进阶测试：验证"部分覆盖"

你也可以改成不同维度的规则，看是否会合并而不是完全覆盖：

|文件|内容|
|---|---|
|`/CLAUDE.md`|"禁止使用console.log"|
|`/foo/CLAUDE.md`|"优先使用TypeScript"|

在 `foo/bar/` 下问："我有哪些编码规范？"

**预期结果**：两条都生效 → "禁止console.log + 优先TypeScript"（合并，非覆盖）
