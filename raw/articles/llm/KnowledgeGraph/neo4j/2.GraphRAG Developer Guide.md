Graph databases provide unmatched data organization, flexibility, and standardization, making it easy to write diverse queries and answer more questions. [GraphRAG (retrieval-augmented generation with graphs)](https://neo4j.com/blog/genai/what-is-graphrag) extends these benefits to AI, enabling developers to build more accurate, agile, and extensible GenAI apps and agentic systems. Use these resources to get started today!

## How to Get Started

1. For a high level overview, have a look at [neo4j.com/genai](https://neo4j.com/generativeai/)
2. To build a knowledge graph from unstructured data, such as text documents, see [Creating Graphs From Unstructured Data](https://neo4j.com/developer/genai-ecosystem/importing-graph-from-unstructured-data/). You can also experiment with the [LLM-Knowledge Graph Builder](https://neo4j.com/labs/genai-ecosystem/llm-graph-builder), a reference UI implementation built on top of Neo4j and LangChain integrations.
3. If you want to learn more, take one of the [GenAI GraphAcademy courses](https://graphacademy.neo4j.com/categories/llms/?ref=genai-docs) or have a look at the below [Example Projects & Use Case Applications](#example-projects)
4. Pick your [GenAI framework of choice](https://neo4j.com/labs/genai-ecosystem/genai-frameworks) and start building your own GenAI applications with Neo4j.
