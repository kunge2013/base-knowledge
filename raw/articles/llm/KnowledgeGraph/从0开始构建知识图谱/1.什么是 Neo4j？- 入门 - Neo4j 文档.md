## 什么是 Neo4j？

![neo4j architecture diagram](https://neo4j.ac.cn/docs/getting-started/_images/neo4j-architecture-diagram.svg)

Neo4j 是一款 *原生图 [数据](#) 库* ，这意味着它在存储层实现了真正的 图 模型。数据并不是在其他技术之上使用“图抽象”，而是以您在白板上构思想法的相同方式存储在 Neo4j 中。

数据库管理

自 2007 年以来，Neo4j 已发展成为一个丰富的工具、应用程序和库生态系统。该生态系统允许您通过此处描述的多种方式将图技术集成到您的工作环境中。

除了核心图功能外，Neo4j 还提供 ACID 事务、 集群 支持和运行时故障转移。

Neo4j 使用 [Java](#) 和 Scala 编写。您可以在 [GitHub](https://github.com/neo4j/neo4j) 上查看源代码。

## 如何与 Neo4j 交互

Neo4j 使用 [Cypher®](https://neo4j.ac.cn/docs/getting-started/cypher/) ，这是一种声明式查询语言，类似于 SQL，但针对图进行了优化。其他数据库（如 SAP HANA Graph）也通过 [openCypher 项目](http://www.opencypher.org/) 使用同一种语言。

另一种选择是使用 [库](https://neo4j.ac.cn/docs/create-applications) 。Neo4j 目前支持 Java、JavaScript、.NET、Python、Go、GraphQL、Spring 等。

### 全托管云服务

[Neo4j AuraDB](https://neo4j.ac.cn/cloud/platform/aura-graph-database/) 是一项全托管的云服务，让您可以直接从浏览器开始探索 Neo4j。

如果您是一名数据科学家，您可能还想查看 [Neo4j AuraDS](https://neo4j.ac.cn/docs/aura/aurads/) ，并获取超过 65 种预调优的 [图算法](https://neo4j.ac.cn/docs/graph-data-science/current/algorithms/) 的使用权限。

Neo4j Aura 提供免费版和订阅版。 [查看完整对比](https://neo4j.ac.cn/pricing/) 。

### 自管理云服务

您也可以在您选择的 [云平台](https://neo4j.ac.cn/docs/operations-manual/current/cloud-deployments) 上部署图数据库。Neo4j 支持 Amazon Web Services (AWS)、Google Cloud (GCP) 和 Microsoft Azure。

数据库管理

Neo4j 可在 [Linux](https://neo4j.ac.cn/docs/operations-manual/current/installation/linux/) 、 [macOs](https://neo4j.ac.cn/docs/operations-manual/current/installation/osx/) 和 [Windows](https://neo4j.ac.cn/docs/operations-manual/current/installation/windows/) 上安装。

### 自管理本地部署

如果您倾向于使用本地部署：如果不在生产环境中工作，请安装 [Neo4j Desktop](https://neo4j.ac.cn/docs/desktop-manual) ；或者直接在本地 [安装 Neo4j](https://neo4j.ac.cn/docs/operations-manual/current/installation/) 。

## 处理数据

创建 [数据](#) 库后，您的学习路径取决于您是想处理自己的数据，还是使用 Neo4j 的示例数据集。

数据库管理

- **自有数据** ：有多种方法可以将数据 [导入](https://neo4j.ac.cn/docs/import) 到 Neo4j 并对其进行 [建模](https://neo4j.ac.cn/docs/getting-started/data-modeling/) ，以获得更好的体验。
- **示例数据集** ： [Aura](https://neo4j.ac.cn/docs/aura) 和 [Neo4j Browser](https://neo4j.ac.cn/docs/browser-manual/) 都内置了引导指南，允许您创建示例数据集并开始查询。要访问它们，请使用 Aura 右上角的毕业帽图标，或在 Neo4j Browser 中输入 `:guide` 。  
	您也可以 [下载](https://neo4j.ac.cn/docs/getting-started/appendix/example-data/) 示例数据集，然后将其导入到您的实例中。

### Neo4j 工具

Neo4j 拥有一个工具目录，可用于 [数据库管理](#) 、数据可视化等多种用途。您可以在 [Tools](https://neo4j.ac.cn/docs/tools) 中心查看所有产品。

### 支持的库

Neo4j 支持多种最流行的 [查询语言](https://neo4j.ac.cn/docs/create-applications) ，并提供专有库以提供定制化的体验。

- [Neo4j Graph Data Science (GDS)](https://neo4j.ac.cn/docs/gds/) 库提供了常用图算法的实现，以及用于训练预测性监督模型的机器学习流水线。您可以使用它们来解决图问题，例如预测缺失的关系。
- [对象图映射 (OGM)](https://neo4j.ac.cn/docs/ogm-manual) 库将图中的节点和关系映射为领域模型中的对象和引用。您可以使用此资源来开始跟踪更改，并最小化必要的更新和传递持久性（读取和更新对象的邻域）。
