## Cypher 入门

本教程展示了 [Cypher®](https://neo4j.ac.cn/docs/getting-started/cypher/) （Neo4j 的查询语言）的基本概念，包括如何创建和查询图。你将学习创建图、查找节点、查询模式以及解决有关图的问题。

## 创建电影图

创建 [免费 Aura 实例](https://neo4j.ac.cn/product/auradb/#docs-nav-get-started) 后，点击“Connect”（连接）按钮并选择“Query”（查询）。在 Cypher 编辑器中，复制并粘贴以下 Cypher 代码并执行查询：

```cypher
CREATE CONSTRAINT movie_title IF NOT EXISTS FOR (m:Movie) REQUIRE m.title IS UNIQUE;
CREATE CONSTRAINT person_name IF NOT EXISTS FOR (p:Person) REQUIRE p.name IS UNIQUE;
```

### 特定的演员

如果你想在图中查找特定的演员，可以 `MATCH` （匹配） `Person` 节点，并使用 `name` 属性来引用该演员：

数学

```cypher
MATCH (tom:Person {name:"Tom Hanks"})
RETURN tom
```

注意， `WHERE` 子句引用的是你为 `Person` 节点设置的变量（ `tom` ），而不是节点标签。

### 特定的电影

查询特定电影时也是如此，例如“Cloud Atlas”（云图）。现在，不再匹配 `Person` 节点，而是查询 `Movie` 节点，并使用 `WHERE` 子句通过 `title` 属性定位电影：

```cypher
MATCH (cloudAtlas:Movie)
WHERE cloudAtlas.title = "Cloud Atlas"
RETURN cloudAtlas
```

### 限制返回结果

如果你想在没有特定顺序的情况下限制返回结果的数量，可以在 `RETURN` 子句中添加 `LIMIT` 。此查询将查找图中的所有 `Person` 节点，并使用 `name` 属性返回其中的 10 个。

```cypher
MATCH (p:Person)
RETURN p.name LIMIT 10
```

对于此查询，返回的是属性值，你只能以表格形式查看结果。

```cypher
MATCH (nineties:Movie)
WHERE nineties.released = 1990
RETURN nineties.title
```

数学

### 汤姆·汉克斯的所有电影

要列出汤姆·汉克斯参演的所有电影，你需要查询他的 `Person` 节点，以及它如何通过关系连接到 `Movie` 节点。

数据管理

```cypher
MATCH (tom:Person {name: "Tom Hanks"})-[r]->(tomHanksMovies:Movie)
RETURN tom,r,tomHanksMovies
```

### “Cloud Atlas”的导演

如前所述，你可以通过 `DIRECTED` 关系找到有关导演的信息。要了解谁执导了“Cloud Atlas”，请执行以下查询：

### 汤姆·汉克斯的联合主演

如果你想扩展模式并找到在同一部电影中合作过的演员，可以使用以下查询：

```cypher
MATCH (tom:Person {name:"Tom Hanks"})-[a:ACTED_IN]->(m:Movie)<-[b:ACTED_IN]-(coActors:Person)
```

为了更好地理解上述查询，我们将其拆解。首先，查询找出汤姆·汉克斯参演了哪些电影：

```cypher
MATCH (tom:Person {name: "Tom Hanks"})-[a:ACTED_IN]->(m:Movie)
```

```cypher
MATCH (m)<-[b:ACTED_IN]-(coActors:Person)
```

### 与“Cloud Atlas”相关的人

如果你不知道 `Person` 和 `Movie` 节点之间通过什么关系连接，可以查询图来发现它们：

数据管理

```cypher
MATCH (people:Person)-[relatedTo]-(:Movie {title: "Cloud Atlas"})
RETURN people.name, type(relatedTo), relatedTo
```

在此查询中，关系是无向且未指定的，因为你希望检索这两个节点之间的所有关系，无论方向如何，也不管图中存在什么关系。然后，在 `RETURN` 行中，你可以指定想要检索的属性，而不是获取所有可用的属性（如前述步骤所示）。

在 Cypher 中，你可以通过组合变量和属性名称来定义要检索的特定属性。因此，在这种情况下， `people` 是 `Person` 节点的变量， `name` 是存储人员姓名的属性，因此写作 `people.name` 。

然后，由于未指定关系，你可以使用 [`type()` 函数](https://neo4j.ac.cn/docs/cypher-manual/current/functions/scalar/#functions-type) 来检索关系类型，并使用 `relatedTo` 来检索与该关系关联的所有属性（例如在 `:ACTED_IN` 情况下的 `roles` ）。

### 与凯文·贝肯相关的电影和演员

“凯文·贝肯的六度分隔”游戏的前提是通过电影联合主演将任何演员与凯文·贝肯联系起来，步数不超过六步。这个游戏可以在电影图中使用不同的策略进行体验。

数学

两种可能的策略：

- [变长模式](https://neo4j.ac.cn/docs/cypher-manual/current/patterns/variable-length-patterns/)
- [内置的 shortestPath() 算法](https://neo4j.ac.cn/docs/cypher-manual/current/patterns/shortest-paths/)

为了简单起见，本示例仅展示距离凯文·贝肯三跳以内的关系，而不是六跳。

#### 变长模式

此查询查找距离凯文·贝肯一到三跳的所有 `Person` 和 `Movie` 节点：

```cypher
MATCH (bacon:Person {name:"Kevin Bacon"})-[*1..3]-(a:Person)
RETURN DISTINCT bacon, a
```

`RETURN` 子句包含一个 `DISTINCT` 运算符，以确保结果不会重复。在此查询中，凯文·贝肯可能在不同的电影中与同一位演员合作过，但你只需要唯一的结果。

结果如下：

[![Result to query for what actors are related to Kevin Bacon](https://neo4j.ac.cn/docs/getting-started/_images/kevinthreehops.svg)](https://neo4j.ac.cn/docs/getting-started/_images/kevinthreehops.svg)

此查询的缺点是你不知道凯文·贝肯是 *如何* 与这些人或电影建立联系的。如果你想检索连接这些节点的路径，请 `MATCH` （匹配） **路径** ，并将其与相关的 `Person` 或 `Movie` 节点一起返回：

数据管理

```cypher
MATCH p = (bacon:Person {name:"Kevin Bacon"})-[*1..3]-(a:Person)
RETURN DISTINCT bacon, a, p
```

`p` 变量指的是凯文·贝肯与他一到三跳内相关的 `Person` 节点之间的整条路径。然后 `p` 变量在 `RETURN` 子句中被引用。

现在结果中也包含了 `Movie` 节点，因为这就是凯文·贝肯与其他 `Person` 节点建立联系的方式。

[![Three hops from Kevin Bacon and other actors and movies](https://neo4j.ac.cn/docs/getting-started/_images/kevinthreehopsrel.svg)](https://neo4j.ac.cn/docs/getting-started/_images/kevinthreehopsrel.svg)

### shortestPath 算法

要找到两个演员之间的最短路径，请按如下方式使用该算法并返回路径：

```cypher
MATCH p=shortestPath(
  (bacon:Person {name:"Kevin Bacon"})-[*]-(meg:Person {name:"Meg Ryan"})
)
RETURN p
```

这是该查询的结果：


这意味着所有节点和关系都已被删除。
