## 数据建模工具

有一系列无代码工具帮助您开始 [数据](#) 建模。这里列出了一些可用的工具。

计算机科学

## Neo4j Data Importer

![600](https://neo4j.ac.cn/docs/getting-started/_images/data-importer-1.png)

Neo4j Data Importer 将数据建模集成到 [导入过程](https://neo4j.ac.cn/docs/getting-started/data-import/) 中，并让您绘制图模型并将数据映射到该模型。您可以访问它

- 通过 **Import** （导入）在 [Neo4j Aura](https://neo4j.ac.cn/product/auradb/#docs-nav-get-started) 中。
- 作为独立版本， [仅限安全连接](https://data-importer.neo4j.io/) 或 [支持安全和非安全连接](https://data-importer.graphapp.io/) 。

欲了解更多信息，请参阅 [Neo4j Data Importer 文档](https://neo4j.ac.cn/docs/data-importer/) 。

## 其他工具

还有其他非 Neo4j 的工具可用于数据建模

- [Mermaid](https://mermaid.live/) ：通用数据建模工具（不专为图数据库设计），基于 Markdown。非常适合记录建模策略。
- [PlantUML](https://plantuml.com/) ：从纯文本创建图表的应用程序。更适合版本控制，而非模型设计。
- [Hackolade](https://hackolade.com/) ：用于设计、记录和交流数据模型与模式的工具。专为支持 Neo4j 中的节点标签和关系类型等特定数据建模而构建。
