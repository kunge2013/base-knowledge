入门指南：项目与资源

## Projects and resources 项目与资源

Projects and resources are the building blocks of the Palantir platform, powered by the [Compass application](https://www.palantir.com/docs/foundry/compass/overview/).  
项目和资源是 Palantir 平台的基石，而 Compass 应用程序则为其提供了强大的支持。

## Resources 资源

Working in the platform often involves creating **resources**. These include datasets which are the outputs of a data connection or a transform, or manually uploaded data, and the artifacts from various platform applications like repositories, analyses, reports, or applications.  
在平台上工作通常意味着需要创建各种资源。这些资源包括从数据连接或数据处理过程中得到的数据集，以及手动上传的数据。此外，还包括来自各种平台应用的成果，比如数据库、分析结果、报告等。

A *resource* is analogous to a *file* in a traditional system. In the Palantir platform, we use the term "resource" to avoid confusion, as some resources, such as a dataset or a code repository, can contain files within them.  
在传统系统中，资源类似于文件。在 Palantir 平台上，我们使用“资源”这个词以避免混淆，因为有些资源，比如数据集或代码库，内部可能还包含其他文件。

While each resource type opens in a different platform application, resources share some common information. Some examples include who last updated a resource and when; which users have access at different levels; features like leaving comments and marking favorites; and interactions like moving, sharing, and trashing. Additionally, each resource has a unique identifier called a resource identifier, or RID, which is standardized across applications.  
虽然每种资源类型都在不同的平台应用程序中打开，但资源之间还是共享了一些共同的信息。例如，谁是最最近一次更新该资源的人以及具体时间；哪些用户拥有不同的权限；诸如留下评论、标记 favorite 等功能；以及诸如移动、分享和删除等交互操作。此外，每种资源都有一个唯一的标识符，称为资源标识符或 RID，这个标识符在各个应用程序中是标准化的。

## Projects 项目

Resources live within **Projects**, which form boundaries between groups of related resources and provide features to enable collaboration. These features include managing permissions for who can access the project resources; showing you the latest project activity and metrics about usage; and curating project metadata like documentation, key resources, and data health. Each project has a list of users or groups who have access to the project and are assigned **Viewer**, **Editor**, or **Owner** permissions on project resources. Within projects, resources can be organized into **folders** to provide further structure and keep things clean.  
资源存在于项目中，项目之间形成了资源组的边界，同时提供了支持协作的功能。这些功能包括管理访问项目资源的权限、显示最新的项目活动和使用指标，以及管理项目元数据，如文档、关键资源和数据状态等。每个项目都有一组拥有访问权限的用户或组，他们可以分别担任查看者、编辑者或所有者的角色，对项目资源进行管理。在项目中，资源可以被归类到文件夹中，以便更好地组织资源并保持整洁的秩序。

In addition to projects created for collaboration, every user has a personal project. You can access your Project by navigating to **Files** from the workspace navigation sidebar and then selecting **Projects**. As you start to use applications, resources you create will appear in your personal Project by default.  
除了为协作而创建的项目之外，每个用户还都有属于自己的个人项目。你可以通过在工作区导航 sidebar 中的“文件”菜单下选择“项目”来访问自己的项目。当你开始使用各种应用程序时，你创建的资源默认会出现在你的个人项目中。
