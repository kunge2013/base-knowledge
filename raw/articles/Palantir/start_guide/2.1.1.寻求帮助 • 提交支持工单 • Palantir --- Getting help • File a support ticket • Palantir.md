## 1\. Create an example重试 错误原因

When asking a question about a problem you encounter, providing clear steps that we can use to reproduce the problem will ensure a speedy resolution. These should be:重试 错误原因

- **Minimal:** Use as few steps as possible while still producing the problem.重试 错误原因
- **Complete:** Provide all parts needed to reproduce the problem.重试 错误原因
- **Verifiable:** Test the workflow you are about to provide to make sure it reproduces the problem.重试 错误原因

A minimal, complete, and verifiable example helps us reproduce the problem outside your environment and in return, makes it easier to get to the root cause of your problem and reach a faster resolution.重试 错误原因

In the Palantir context, such an example can either be a series of steps that reproduces the behavior or a minimal resource that reproduces the issue. Generally, it is useful to include expected behavior versus the observed behavior as part of your example.重试 错误原因

### Tips重试 错误原因

Here are some tips for creating a minimal, complete, and verifiable example:重试 错误原因

- Start by identifying the steps required to reproduce the issue. The more specific and detailed these steps are, the easier it will be for someone else to reproduce the issue.重试 错误原因
- Make sure that your example is minimal, meaning that it includes only the bare minimum amount of information needed to reproduce the issue. This will help to narrow down the potential causes of the issue and make it easier to fix.重试 错误原因
- Include the expected result of the steps you provided, as well as the actual result. This will help others to understand the problem and determine if they are experiencing the same issue.重试 错误原因
- Make sure that your example is complete, meaning that it includes all the information necessary to reproduce the issue. If you leave out any important details, it will be difficult for others to reproduce the issue and help you solve the problem.重试 错误原因
- Finally, make sure that your example is verifiable, meaning that others can easily reproduce the issue using the information you provided. If your example is not verifiable, it will be difficult for others to help you fix the problem.重试 错误原因

如果在指定的应用程序中出现问题，请前往“支持”菜单，选择“报告问题”（或“支持>联系客服”），然后按照提示操作即可。

作为一种替代方案，您也可以向 Palantir 开发者社区的其他用户寻求支持。
