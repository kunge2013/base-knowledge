## Set up a webhook设置好 Web 钩子功能。

## Prerequisites 先决条件

1. Complete the [getting started](https://www.palantir.com/docs/foundry/action-types/getting-started/) tutorial to learn about how to set up a basic action.  
	完成入门教程，了解如何设置一个基本的动作。
2. Set up a [webhook](https://www.palantir.com/docs/foundry/data-connection/webhooks-setup/) to create a connection to an external system. You may need to work with a system administrator who has permissions to connect to source systems before creating a webhook.  
	请设置一个 Web 钩子，以建立与外部系统的连接。在创建 Web 钩子之前，你可能需要与具有连接源系统权限的系统管理员合作。

## Steps 步骤

In the below example, suppose that we have a webhook called **Modify ticket priority** which accepts a `priority` string value and sends it to an external system.  
在下面的例子中，假设我们有一个名为“修改任务优先级”的 Web 钩子函数。该函数接受一个 `priority` 类型的字符串值，并将其发送到外部系统。

Navigate to your action, select the **Logic** tab, select **Add new rule**, then select **Webhook**.  
请进入您的操作界面，选择“逻辑”标签，然后选择“添加新规则”，最后选择“Webhook”。

![Add new webhook](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-add-new-rule-webhook.png?width=600)

By default, the newly added webhook is configured as a **side effect**; this makes the webhook run *after* objects are edited in Foundry. Alternatively, select **Writeback** to have the webhook run *before* object edits.  
默认情况下，新添加的 Web 钩子会被配置为在对象被编辑后自动触发。或者，可以选择“Writeback”模式，让 Web 钩子在对象编辑之前就触发。

![Select writeback or side effect](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-select-writeback-or-side-effect.png?width=400)

In the menu below, select the webhook you want to execute. In this example, we select the **Modify ticket priority** webhook. If you wish, you can select a different version of the webhook.  
在下面的菜单中，选择你想要执行的 Web 钩子功能。在这个示例中，我们选择了“修改工单优先级”的 Web 钩子。如果你愿意，可以选择其他版本的 Web 钩子功能。

![Select webhook to execute](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-select-webhook-to-execute.png?width=400)

Next, configure webhook input parameters based on action parameters. By default, a new action parameter is generated for each webhook input unless an existing action parameter with the same name already exists, in which case the existing parameter is automatically configured. In this example, we map the webhook input called `priority` to an existing action parameter called `Ticket Priority`.  
接下来，需要根据动作参数来配置 Web 钩子输入参数。默认情况下，每个 Web 钩子输入都会生成一个新的动作参数；除非已经存在同名的其他动作参数，否则会自动使用现有的参数。在示例中，我们将名为 `priority` 的 Web 钩子输入参数映射到名为 `Ticket Priority` 的现有动作参数上。

![Mapping webhook input to an existing action parameter](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-input-mapping-example.png?width=400)

Select **Add webhook** to complete adding the webhook rule to your action. Note that after the webhook is added, the Rules section shows that the writeback will occur before objects are modified.  
选择“添加 Web 钩子”以完成将 Web 钩子规则添加到您的操作中。请注意，在添加 Web 钩子后，规则部分会显示在对象被修改之前就会进行数据写入操作。

![Add new webhook (completed)](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-add-webhook-complete.png?width=600)

You may want to remove any autogenerated parameters created when you added the webhook which are now unused.  
你可能需要删除那些在添加 Web 钩子时自动生成的参数，因为这些参数现在已经不再需要使用了。

![Remove autogenerated parameters](https://www.palantir.com/docs/resources/foundry/action-types/webhooks-remove-autogenerated-parameters.png?width=600)

Select **Save** in the top-right to save your changes to the action. Now, when the action is applied, the request to the external system will be made before any changes are applied to objects in Foundry.  
在右上角选择“保存”，以将您的更改保存到该操作中。现在，当该操作被执行后，会在对 Foundry 中的对象进行任何修改之前，先向外部系统发送请求。
