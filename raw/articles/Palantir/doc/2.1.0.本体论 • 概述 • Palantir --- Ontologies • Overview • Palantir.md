## Ontologies 本体论

An ontology is an artifact which stores ontological resources or entities, including the following:  
本体论是一种用于存储本体资源或实体的工具，其中包括以下内容：

- [Object types 对象类型](https://www.palantir.com/docs/foundry/object-link-types/object-types-overview/)
- [Link types 链接类型](https://www.palantir.com/docs/foundry/object-link-types/link-types-overview/)
- [Action types 操作类型](https://www.palantir.com/docs/foundry/action-types/overview/)
- [Interfaces 接口/界面](https://www.palantir.com/docs/foundry/interfaces/interface-overview/)
- [Shared properties 共有的属性](https://www.palantir.com/docs/foundry/object-link-types/shared-property-overview/)
- [Object type groups 对象类型组](https://www.palantir.com/docs/foundry/object-link-types/type-groups/)

We call these resources **Ontology resources**. An ontology can either be private and assigned to a single [organization](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/) or shared among multiple organizations. Shared ontologies allow users of different organizations to share data and workflows safely. Grouping entities in ontologies ensures that only users of the specified organizations can access ontological entities.  
我们将这些资源称为本体资源。本体可以是私有的，仅属于一个组织，也可以在多個组织之间共享。共享本体使得不同组织的用户能够安全地共享数据和工作流程。在本体中分组实体可以确保只有指定组织的用户才能访问相应的本体元素。

## Relation with spaces 与空间的关系

An ontology is mapped 1:1 with a [space](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/#spaces). When a new space is created, a corresponding ontology with the same name is simultaneously created with the same organization [markings](https://www.palantir.com/docs/foundry/security/markings/) as the space. A private space will map to a private ontology, while a shared space will map to a shared ontology.  
本体与空间之间实行 1:1 映射关系。当创建一个新的空间时，会同时创建一个名称相同的本体，该本体的组织标识与所创建的空间相同。私有空间会对应一个私有本体，而共享空间则对应一个共享本体。
