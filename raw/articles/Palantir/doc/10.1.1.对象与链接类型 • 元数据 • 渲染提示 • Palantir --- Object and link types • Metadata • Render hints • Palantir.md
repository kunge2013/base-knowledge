## Render hints 渲染提示

Foundry uses **render hints** to communicate information about the use of Ontology [properties](https://www.palantir.com/docs/foundry/object-link-types/properties-overview/) to [Object Storage v1 (Phonograph)](https://www.palantir.com/docs/foundry/object-databases/object-storage-v1/) and user applications in the platform. For example, the `sortable` render hint on a string property tells applications to allow users to sort on that property, as in a timeline or a chart.  
铸造厂使用渲染提示来向 Object Storage v1（Phonograph）以及平台中的用户应用程序传达有关 Ontology 属性使用的信息。例如，字符串属性上的 `sortable` 渲染提示告诉应用程序允许用户根据该属性进行排序操作，比如在时间线或图表中展示数据。

Many render hints are tied to reindex performance for an object type. For instance, you can use render hints to indicate to [Object Storage v1 (Phonograph)](https://www.palantir.com/docs/foundry/object-databases/object-storage-v1/) that a property does not need to be aggregated or sorted in applications, so that Object Storage v1 has less work to do when indexing those properties.  
许多渲染提示与对象类型的重新索引性能相关。例如，你可以使用渲染提示来指示 Object Storage v1（Phonograph）类应用程序中某些属性无需进行聚合或排序操作，这样 Object Storage v1 在索引这些属性时所需的处理量就会减少。

You can select and deselect render hints in the properties pane of the property editor (see image below).  
你可以在属性编辑器的属性面板中选中或取消选中渲染提示（参见下图）。

![Render hints](https://www.palantir.com/docs/resources/foundry/object-link-types/render-hints.png)

The following table shares the **Name** and **Description** for each of the available render hints. The table also provides information on two technical aspects of render hints: "Adds raw index?" and "Requires reindex?" (described below).  
下表列出了所有可用渲染提示的名称和描述。此外，表格还提供了关于渲染提示的两个技术方面的信息： “是否添加原始索引？” 以及 “是否需要重新索引？”（详见下文描述）。

- **Adds raw index?是否添加原始索引？**
	- In order to apply a render hint that adds a raw index, Object Storage v1 (Phonograph) stores the render hint information by creating another index when storing the backing dataset.  
		为了应用一个会添加原始索引的渲染提示，对象存储 v1（Phonograph）在存储底层数据集时，会通过创建另一个索引来保存渲染提示信息。
		- Because of this additional index, for the property with a render hint applied, two columns will be counted toward the total number of columns indexed into Object Storage v1 (Phonograph).  
		由于这个额外的索引因素，对于使用了渲染提示的属性，在 Object Storage v1 中会被计为两列，这些列会被计入索引总数中。
		- This explains why deselecting these render hints improves performance of reindex into Object Storage v1 (Phonograph).  
		这解释了为什么取消选择这些渲染提示能够提升对 Object Storage v1 格式数据的重新索引操作的性能。
- **Requires reindex?需要重新索引吗？**
	- Some render hints will be immediately applied in user applications as soon as their selection is saved in the Ontology Manager.  
		当用户应用程序中的选择被保存到 Ontology Manager 后，一些渲染提示就会立即应用于这些应用程序中。
		- For other render hints that require a reindex, the object type's backing datasources must be reindexed into Objects Storage V1 (Phonograph) before the changes will be reflected in user applications.  
		对于其他需要重新索引的渲染提示，必须在将对象类型的后台数据源重新索引到 Objects Storage V1（Phonograph）之后，这些更改才会体现在用户应用程序中。
		- You can wait for the next triggered reindex or you can manually start the reindex by navigating to the **Datasources** tab of the object type and selecting the blue **Reindex** button in the **Phonograph** pane.  
		你可以等待下一次自动重新索引的过程，或者手动触发重新索引操作。只需进入相应对象类型的数据源选项卡，然后选择 Phonograph 面板中的蓝色“重新索引”按钮即可。
