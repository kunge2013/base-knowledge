## Use shared properties on object types在对象类型上使用共享属性。

To update a property on an object type to a shared property, complete the following steps:  
要将某个对象类型的属性更新为共享属性，请按照以下步骤操作：

1. Navigate to the object type in the Ontology Manager.  
	在 Ontology Manager 中导航到对象类型页面。
2. Select the property on the panel that you want to update, then scroll down to the **Shared Property** section of the configuration.  
	在面板中选择想要更新的属性，然后向下滚动到配置的“共享属性”部分。
![Using a shared property](https://www.palantir.com/docs/resources/foundry/object-link-types/convert-shared-property.png?width=500)
3. Use the dropdown menu to select an existing shared property to use, or convert the property to a new shared property with the [shared property creation](https://www.palantir.com/docs/foundry/object-link-types/create-shared-property/) modal.  
	使用下拉菜单来选择现有的共享财产进行使用，或者通过“创建共享财产”的模态窗口将现有财产转换为新的共享财产。

The property will then display as a shared property. To persist the use of the shared property to the Ontology, select **Save** in the upper right.  
此时，该属性将被显示为共享属性。若希望将这种共享属性保留在 Ontology 中，请选择右上角的“保存”按钮。

- When using a shared property on an object, the property ID and API name of the object-specific property will remain unchanged so as to not break existing downstream workflows that leverage them.  
	在对象使用共享属性时，该对象的属性 ID 和 API 名称将保持不变，以避免破坏那些依赖这些属性的现有下游工作流程。
- While associated with a shared property, direct edits to property metadata that is inherited from the shared property will be disabled. You can still add, delete, or edit type classes. When the property is loaded, the resulting set of type classes will be a union of those from the property and its associated shared property.  
	当某个属性被关联到一个共享属性时，对该共享属性继承而来的元数据进行的直接编辑将会被禁用。不过，你仍然可以添加、删除或编辑类型类。当该属性被加载时，最终出现的类型类集合将会是該属性及其关联共享属性中的类型类的合并结果。
- If the shared property you use has different [render hint](https://www.palantir.com/docs/foundry/object-link-types/metadata-render-hints/) configuration values than the selected property, using the shared property will override the configuration values of the selected property. Make sure your shared property is configured with the proper render hints for your use case.  
	如果你使用的共享属性与所选属性的渲染提示配置值不同，那么使用共享属性将会覆盖所选属性的配置值。请确保你的共享属性已正确配置，以适应你的使用场景需求。

### Detach a shared property from an object将一个共享属性从某个对象中分离出来

To detach a property from a shared property, use the same property panel on an object type in the Ontology Manager and select **Detach**.  
要将某个属性从共享属性中分离出来，可以在本体管理器的对象类型面板中选中该属性，然后选择“分离”选项。

![Detach a shared property](https://www.palantir.com/docs/resources/foundry/object-link-types/detach-shared-property.png?width=500)

Doing so will remove the association between the property and the shared property.  
这样做就能消除该财产与共享财产之间的关联了。
