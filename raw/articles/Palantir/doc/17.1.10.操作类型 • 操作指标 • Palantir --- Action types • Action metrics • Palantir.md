## Action metrics 行动指标

Action metrics display the near real-time usage of an action type over the last 30 days. You can access these metrics from the action type's overview page in [Ontology Manager](https://www.palantir.com/docs/foundry/ontology-manager/overview/), or in [Workflow Lineage](https://www.palantir.com/docs/foundry/workflow-lineage/overview/) by selecting the action node for a given execution. The following metrics are available:  
操作指标展示了过去 30 天内某种操作类型的实时使用情况。你可以在 Ontology Manager 的操作类型概览页面上查看这些指标，或者在选择特定执行的操作节点时，在 Workflow Lineage 中查看相关指标。以下指标是可用的：

- **Success/failure metrics:** Monitor the current status of your actions with success and failure counts. This enables rapid identification of issues and supports proactive troubleshooting, allowing you to address failures as soon as they occur.  
	成功/失败指标：通过记录成功的次数和失败的次数，可以随时监控各项操作的现状。这有助于快速识别问题，并支持及时的故障排除，从而能够在问题发生第一时间进行处理。
- **P95 duration metric:** Track the 95th percentile (P95) execution duration for each action type. This metric highlights the upper range of execution times, helping you detect performance bottlenecks and optimize workflows for consistent and efficient operation.  
	P95 执行时间指标：记录每种操作类型的第 95 百分位数执行时间。该指标能够显示执行时间的最长范围，有助于您发现性能瓶颈，并优化工作流程以实现稳定高效的操作。

You are also able to access [run history](https://www.palantir.com/docs/foundry/aip-observability/run-history/), which provides a complete view of a given action's executions over the past seven days. Learn more about [AIP observability capabilities](https://www.palantir.com/docs/foundry/aip-observability/overview/).  
您还可以查看运行历史记录，该记录包含了过去七天内某个操作的完整执行情况。了解更多关于 AIP 可观测性的功能。

![Screenshot of action metrics in the overview section.](https://www.palantir.com/docs/resources/foundry/action-types/action-metrics-failures.png)

All metrics are updated in near real-time using the latest data from the Foundry Telemetry Service (FTS). This ensures you have access to the most current information for monitoring, debugging, and maintaining the health of your actions.  
所有指标都使用来自 Foundry Telemetry Service（FTS）的最新数据近乎实时地更新。这确保了您能够获取最新的信息，从而方便地监控、调试和维护您的应用程序的运行状况。

You can also embed action metrics directly inside an operational application using the [Observability Chart widget](https://www.palantir.com/docs/foundry/workshop/widgets-observability-chart/) in [Workshop](https://www.palantir.com/docs/foundry/workshop/overview/) to monitor resource health alongside the rest of a workflow.  
您还可以使用工作坊中的可观测性图表组件，将动作指标直接嵌入到运营应用程序中，从而与工作流程中的其他部分一起监控资源的状态。

## Action failure types 行动失败类型

Action metrics do not require action logs to be displayed. Unlike action logs, action metrics track failures.  
动作指标不需要显示动作日志。与动作日志不同，动作指标能够追踪失败情况。

Action metrics have a variety of categories of failures that may be displayed. These categories are:  
动作指标包含多种可能出现的故障类别。这些类别包括：

- **Invalid parameter failure:** The action was submitted with a parameter or parameters that are not valid within the context of the action.  
	参数无效错误：提交的操作中包含了一些无效的参数，这些参数不符合该操作的规范。
- **Scale limit failure:** The action affected more than the permitted limit of object types (by default, usually 10,000).  
	规模限制突破：该操作影响的对象类型数量超过了允许的限度（默认通常为 10,000 个）。
- **Authentication failure:** The user did not pass the security submission criteria for the action.  
	认证失败：该用户未能满足该操作的安全提交标准。
- **Side effect failure:** The action failed due to a webhook or an incorrectly configured side effect.  
	副作用失败：该操作因 Web 钩子问题或配置错误的副作用而失败。
- **Function failure:** The action failed because the underlying function failed. This failure mode is only possible for function-backed actions.  
	功能故障：该操作失败，原因是相关功能出现了问题。这种故障模式仅适用于那些依赖特定功能的操作。
- **User-facing function failure:** The function backing the action threw an error intended to be displayed to the user. This failure mode is only possible for function-backed actions.  
	用户可见功能出错：支持该功能的代码在执行过程中出现了错误，这些错误会被显示给用户。这种故障模式仅发生在支持功能驱动的操作中。
- **Conflict failure:** The action failed due to a conflict, such as a concurrent modification.  
	冲突导致失败：由于冲突的出现，比如同时发生了修改操作，导致任务未能完成。
- **Unclassified failure:** The action failure did not fall into any of the above categories.  
	未分类的故障：该故障并不属于上述任何一类。

## Permissions 权限

To view action metrics, you must be a `viewer` on the action.  
要查看相关操作指标，您必须是该操作的负责人 `viewer` 。
