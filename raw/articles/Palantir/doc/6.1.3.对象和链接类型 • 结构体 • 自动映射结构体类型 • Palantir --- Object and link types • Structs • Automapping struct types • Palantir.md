## Automapping struct properties自动映射结构属性

Automapping allows users to map all columns automatically rather than manually.  
自动映射功能允许用户自动完成所有列的映射，而无需手动操作。

## Automap struct types in Ontology ManagerOntology Manager 中的 Automap 结构类型

If the object has already been created, users can automap all columns by using the **Automap all** feature.  
如果对象已经创建好了，用户可以使用“自动映射所有列”功能来将所有的列进行映射。

1. In Ontology Manager, enter the **Properties** tab and select the desired property.  
	在 Ontology Manager 中，进入“Properties”选项卡，然后选择所需的属性。
2. Under the **Column mapping** tab, select the desired column.  
	在“列映射”选项卡下，选择所需的列。
![The 'Column mapping' tab and the 'Automap all' button.](https://www.palantir.com/docs/resources/foundry/object-link-types/automap-struct-oma.png?width=500)
3. Select **Automap all**.选择“自动地图所有”。

## Automap struct types in Pipeline BuilderPipeline Builder 中的自动映射结构类型

If the object has not yet been created, automapping can be done on initial object creation with the object type creation wizard.  
如果对象尚未创建，可以使用对象类型创建向导在创建对象时自动进行映射操作。

1. In your Pipeline Builder pipeline, open the relevant dataset and select the **All Actions** dropdown in the top right.  
	在您的 Pipeline Builder 中，打开相关的数据集，然后选择右上角的“所有操作”下拉菜单。
![The All actions dropdown in the dataset detail page.](https://www.palantir.com/docs/resources/foundry/object-link-types/automap-struct-pipelinebuilder.png?width=500)
2. Select **Create object type** to create a new object.  
	选择“创建对象类型”以创建一个新的对象。
![The Properties tab in the 'Create a new object' dialog.](https://www.palantir.com/docs/resources/foundry/object-link-types/automap-struct-properties.png?width=500)
3. Under **Properties**, add the desired properties to be mapped.  
	在“属性”选项中，添加需要映射的属性。
4. Select **Next** and complete the remaining steps to create an automapped object type.  
	选择“下一步”，然后完成剩余的步骤，以创建自动映射的对象类型。
