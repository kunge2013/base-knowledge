## Structs 结构/框架

A **struct** is an Ontology property [base type](https://www.palantir.com/docs/foundry/object-link-types/base-types/) that allows users to create schema-based properties with multiple fields. Struct properties are created from struct type dataset columns. Struct property fields can have different data sources as long as the property is transformed into a single struct type column before being defined in the Ontology.  
“结构”是一种本体属性基础类型，它允许用户创建包含多个字段的基于模式的属性。结构属性是由结构类型的数据集列生成的。只要在这些属性被定义在本体中之前进行了转换，使其变为单一的结构类型列，那么结构属性字段就可以来自不同的数据源。

Many common object properties can be modeled as structs. For example, a `Full Name` property with the fields `First Name` and `Last Name`, or an `Address` property that includes `Street`, `City`, `Postal Code`, and `Country` fields.  
许多常见的对象属性可以建模为结构体。例如，一个包含 `First Name` 和 `Last Name` 字段的 `Full Name` 属性，或者一个包含 `Street` 、 `City` 、 `Postal Code` 和 `Country` 字段的 `Address` 属性。

## Struct configuration 结构配置

The following is a list of struct property constraints and allowed configurations:  
以下是结构属性的约束条件以及允许的配置列表：

- Structs have a depth of one and cannot be nested.  
	这些结构具有一层深度，且不能嵌套其他结构。
- Structs must have at least 1 field.  
	结构体必须至少包含一个字段。
- Only the following field types are currently supported:  
	目前仅支持以下字段类型：
	- `BOOLEAN`
		- `BYTE`
		- `DATE`
		- `DECIMAL`
		- `DOUBLE`
		- `FLOAT`
		- `GEOPOINT`
		- `INTEGER`
		- `LONG`
		- `SHORT`
		- `STRING`
		- `TIMESTAMP`

## Query semantics 查询语义

Structs are indexed similarly to [ElasticSearch object field types ↗](https://www.elastic.co/docs/reference/elasticsearch/mapping-reference/object), which means that arrays can have unintuitive behavior. For example, if you have an array of `Full Name` properties, an object containing `[{"firstName": "Harvey", "lastName": "Dent"}, {"firstName": "Two", "lastName": "Face"}]` would match a query for `"firstName": "Harvey" AND "lastName": "Face"`. The two conditions are treated independently, rather than requiring to match on the same struct within the array.  
这些结构体与 ElasticSearch 中的对象字段类型有着类似的索引方式，这意味着数组可能会表现出一些不直观的行为。例如，如果你有一个包含 `Full Name` 属性的数组，那么包含 `[{"firstName": "Harvey", "lastName": "Dent"}, {"firstName": "Two", "lastName": "Face"}]` 属性的对象将会与查询 `"firstName": "Harvey" AND "lastName": "Face"` 匹配。这两种条件是独立处理的，而不需要确保在数组内的同一结构上才能匹配到相应的值。

## Current levels of support目前的支持程度

As support for struct property types expands, availability will vary across the Palantir platform.  
随着对结构属性类型的支持范围的扩大，其可用性将在 Palantir 平台的不同区域之间有所差异。

Structs are currently supported in the following applications and services:  
目前，这些结构在以下应用和服务中得到了支持：

- **[Ontology Manager](https://www.palantir.com/docs/foundry/ontology-manager/overview/):** Define and edit structs.  
	本体管理器：用于定义和编辑结构体。
- **[Actions](https://www.palantir.com/docs/foundry/action-types/overview/):** Use actions to [create and modify struct property values](https://www.palantir.com/docs/foundry/action-types/actions-on-structs/).  
	操作：使用这些操作来创建和修改结构属性的值。
- **[Pipeline Builder](https://www.palantir.com/docs/foundry/pipeline-builder/overview/):** Define and edit structs.  
	管道构建器：定义和编辑结构体。
- **[Workshop](https://www.palantir.com/docs/foundry/workshop/overview/):** Display and use struct properties as variables.  
	研讨会：展示如何将结构属性作为变量来使用。
- **[Marketplace](https://www.palantir.com/docs/foundry/marketplace/overview/):** Package and install struct properties.  
	市场平台：打包并安装结构属性。
- **[Object Explorer](https://www.palantir.com/docs/foundry/object-explorer/search-objects/):** Search for objects by their struct property values (struct field search is under development).  
	对象浏览器：可以通过对象的 struct 属性值来搜索对象（struct 字段搜索功能正在开发中）。
- **[Ontology SDK](https://www.palantir.com/docs/foundry/ontology-sdk/overview/):** Load struct properties and search for objects by their struct property values in Ontology SDK applications. Not all Ontology SDKs support struct properties. Refer to the OSDK [unsupported property types](https://www.palantir.com/docs/foundry/ontology-sdk/unsupported-types/#object-types-unsupported-property-types) for more information.  
	Ontology SDK：在 Ontology SDK 应用程序中，可以通过结构体属性来加载对象属性，并根据结构体属性的值来搜索相应的对象。并非所有 Ontology SDK 都支持结构体属性功能。更多相关信息，请参考 Ontology SDK 不支持的属性类型列表。
- **[Functions](https://www.palantir.com/docs/foundry/functions/overview/):** Struct parameters and struct property edits are supported in TypeScript v2 and Python functions.  
	功能：在 TypeScript 2 版本和 Python 语言中，都支持对结构体参数和结构体属性进行编辑。

Structs will not be supported in Object Storage v1 (Phonograph) and can currently only be created from datasets and Restricted Views.  
在 Object Storage v1（Phonograph）版本中，不支持创建结构化的数据对象。目前，结构化的数据对象只能从数据集和受限视图中创建。
