## Add action types to Marketplace product将操作类型添加到 Marketplace 产品中

Use [Foundry DevOps](https://www.palantir.com/docs/foundry/devops/overview/) to include your action types in [Marketplace products](https://www.palantir.com/docs/foundry/devops/core-concepts/#product) for other users to install and reuse. [Learn how to create your first product.](https://www.palantir.com/docs/foundry/foundry-devops/create-products/)  
使用 Foundry DevOps 工具，将你的应用程序类型添加到市场产品中，以便其他用户能够安装和复用这些应用程序。了解如何创建你的第一个产品。

## Supported features 支持的功能

Most action type features are supported, except actions that reference [object types with unsupported features](https://www.palantir.com/docs/foundry/object-link-types/marketplace-ontology-types/#unsupported-features). When preparing your action type for packaging, ensure your action type [**Security & Submission criteria**](https://www.palantir.com/docs/foundry/action-types/getting-started/#add-submission-criteria) does not reference a user; update any user references to refer to groups instead.  
大多数动作类型的功能都得到了支持，不过那些涉及使用不支持的对象类型的动作的功能则不受支持。在准备将你的动作类型打包时，请确保“安全与提交”相关的标准中没有引用到用户；同时，将所有对用户的引用改为对组的引用。

## Adding action types to products为产品添加操作类型

To add an action type to a product, first [create a product](https://www.palantir.com/docs/foundry/foundry-devops/create-products/) and then select the **Action type** content type as below.  
要为一个产品添加操作类型，首先创建一个产品，然后选择相应的操作类型内容类型，如下所示。

![Add action type.](https://www.palantir.com/docs/resources/foundry/action-types/marketplace-add-action-type.png)

You will then be prompted to choose an action type.  
然后，你会被提示选择一种操作类型。

![Add action type dialogue.](https://www.palantir.com/docs/resources/foundry/action-types/marketplace-add-action-type-dialog.png)

While you can select action types directly, we recommend first adding content like [Workshop applications](https://www.palantir.com/docs/foundry/workshop/marketplace-workshop/) and then selecting relevant actions via the dependencies panel as shown below.  
虽然可以直接选择操作类型，但我们建议先添加如“工坊应用”这样的内容，然后通过依赖关系面板来选择相关的操作，如下所示。

![Add action type via panel.](https://www.palantir.com/docs/resources/foundry/action-types/marketplace-add-action-type-panel.png)
