## Create a struct property type创建一种结构体属性类型。

Create and configure a new struct property from the **Object types** page in Ontology Manager. For more information about struct properties, see the [overview](https://www.palantir.com/docs/foundry/object-link-types/structs-overview/).  
在 Ontology Manager 的“对象类型”页面中创建并配置一个新的结构体属性。有关结构体属性的更多信息，请参见概述部分。

1. In Ontology Manager, open the **Object types** tab in the left sidebar and select an existing object type.  
	在 Ontology Manager 中，打开左侧侧边栏中的“对象类型”选项卡，然后选择一个现有的对象类型。
2. In the object type details page, open the **Properties** tab in the left sidebar, and select the **Create property** button on the top right of the **Properties** table.  
	在对象类型详情页面中，打开左侧侧边的“属性”选项卡，然后选择“属性”表格右上角的“创建属性”按钮。
![The object type Properties table and 'Property editor' panel.](https://www.palantir.com/docs/resources/foundry/object-link-types/create-struct-from-ontology-manager.png?width=500)
3. In the **Property editor** panel, add a name and description, and select **Struct** from the **Base type** dropdown menu.  
	在属性编辑面板中，添加一个名称 và描述，然后从基础类型下拉菜单中选择“Struct”。
![The Base type dropdown with 'Struct' selected.](https://www.palantir.com/docs/resources/foundry/object-link-types/name-struct-from-ontology-manager.png?width=500)
4. Scroll down to the **Data** section and select a **Backing column** from the dropdown.  
	向下滚动到“数据”部分，然后从下拉菜单中选择一个“ backing”列。
![Choose a backing column in the Data section of the Property editor.](https://www.palantir.com/docs/resources/foundry/object-link-types/backing-column-struct-ontology-manager.png?width=500)
5. In the **Struct fields** section, select **Add field**, then **New field**.  
	在“Struct 字段”部分，选择“添加字段”，然后选择“新字段”。
![Sample struct fields in a struct property type.](https://www.palantir.com/docs/resources/foundry/object-link-types/struct-field-ontology-manager.png?width=500)
6. Name the new struct field and optionally add a description.  
	为新的结构体添加字段名称，并可以选择添加描述。
7. Lastly, map a column from a datasource to the new struct field.  
	最后，将数据源中的一列数据映射到新的结构体字段上。
