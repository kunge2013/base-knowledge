## Use a Python function in Pipeline Builder在 Pipeline Builder 中使用一个 Python 函数

Pipeline Builder supports both Java and Python user-defined functions (UDF). [Learn more about Java UDFs](https://www.palantir.com/docs/foundry/transforms-java/user-defined-functions/).  
Pipeline Builder 支持使用 Java 和 Python 编写的用户自定义函数。更多关于 Java UDF 的信息请点击此处了解。

## Prerequisites 先决条件

This guide assumes you have already authored and published a Python function. Review our [getting started with Python functions](https://www.palantir.com/docs/foundry/functions/python-getting-started/) documentation for a tutorial.  
本指南假设您已经编写并发布了一个 Python 函数。如需了解相关教程，请参考我们的《Python 函数使用指南》文档。

## Architecture 建筑学

Python functions run in a Pipeline Builder pipeline as a sidecar container. This means that the function does not need to be deployed and scales dynamically with the size of your pipeline. Embedded functions can be [previewed](https://www.palantir.com/docs/foundry/pipeline-builder/outputs-preview-pipeline/) similarly to other transforms in Pipeline Builder.  
在 Pipeline Builder 中，Python 函数作为辅助容器运行。这意味着这些函数无需进行部署，也可以根据管道的规模动态扩展。与 Pipeline Builder 中的其他转换功能一样，这些嵌入式函数也可以进行预览。

## Use your function in a Pipeline Builder pipeline请在 Pipeline Builder 项目中使用你的函数。

Follow the steps below to prepare and configure a Python function in your pipeline:  
请按照以下步骤来准备并配置一个 Python 函数，将其集成到你的处理流程中：

1. Open the Pipeline Builder pipeline in which you want to use your Python function.  
	打开你想要使用 Python 函数的 Pipeline Builder 管道。
![A Python function in Pipeline Builder.](https://www.palantir.com/docs/resources/foundry/functions/python-functions-builder.png?width=800px)
2. Import your UDF into Pipeline Builder using one of two methods:  
	你可以使用两种方法中的任何一种将你的 UDF 导入到 Pipeline Builder 中：
	- **From the graph view:  
		从图表视图来看：**
		1. Select **Reusables** from the upper part of the pipeline graph, then choose **User-defined functions**.  
			从管道图表的顶部选择“可复用组件”，然后选择“自定义函数”。  
			  
			![The 'Reusables' button in Pipeline Builder.](https://www.palantir.com/docs/resources/foundry/functions/python-functions-builder-reusable.png?width=500px)  
			  
			2\. Select **Import UDF** and search through the available functions to find the one you want to use 3. Choose **Add** next to the function name. The function should then display an **Imported** tag.  
			2\. 选择“导入 UDF”选项，然后在可用的函数列表中找到想要使用的函数。3. 在函数名称旁边点击“添加”按钮。此时，该函数应该会显示“已导入”的标签。  
			  
			![Add Python function to Pipeline Builder.](https://www.palantir.com/docs/resources/foundry/functions/python-functions-add-builder.png?width=700px)  
			  
			4\. Close the import dialogue and select **Transform** on your Pipeline Builder graph where you would like to use the function. 5. From the list of transforms, find the **UDFs** tab to the left to view your imported functions.  
			4\. 关闭导入对话框，然后在“Pipeline Builder”图中选择“Transform”功能，即可在该图中使用所导入的函数。5. 从转换列表中，找到左侧的“UDFs”选项卡，即可查看已导入的函数。
		- **Use the transform picker:  
		使用变换选择器：**
		1. Select **Transform** on the pipeline builder graph.  
			在管道构建器的图表中选择“Transform”选项。
				2. Enter the name of the UDF you want to import.  
			请输入想要导入的 UDF 的名称。  
			  
			![Search unimported UDFs in Pipeline Builder.](https://www.palantir.com/docs/resources/foundry/functions/python-functions-builder-search-udfs.png?width=500px)  
			  
			3\. Select **Search unimported UDFs**. 4. Hover over the desired UDF and select **Import**.  
			3\. 选择“搜索未导入的 UDFs”。 4. 将鼠标悬停在所需的 UDF 上，然后选择“导入”。  
			  
			![Import UDFs in Pipeline Builder.](https://www.palantir.com/docs/resources/foundry/functions/python-functions-builder-import-udfs.png?width=500px)
3. Fill out the transform definition specifying the input columns and parameters, then select **Apply**.  
	填写变换定义，明确输入列和参数信息，然后选择“应用”。
![Configured Python function transform in Pipeline Builder.](https://www.palantir.com/docs/resources/foundry/functions/python-functions-builder-transform.png?width=700px)

You should now see your Python function on your Pipeline Builder graph and can preview the output of the function.  
现在你应该可以在 Pipeline Builder 的图表中看到你的 Python 函数了，并且可以预览该函数的输出结果。

![Python function in Pipeline Builder](https://www.palantir.com/docs/resources/foundry/functions/python-functions-builder-ete.png?width=900px)

## External API calls in Pipeline Builder在 Pipeline Builder 中进行的外部 API 调用

To make API calls to an external system from Pipeline Builder, you can publish a [Python function with access to external systems](https://www.palantir.com/docs/foundry/functions/api-calls/). This will allow you to write logic that communicates with external systems and use it as part of your pipeline.

To be used as a user-defined function (UDF) in Pipeline Builder, all sources used in your function must be configured to be importable into pipelines. To configure this setting, navigate to the source in Data Connection, then to the **Connection settings > Code import configuration** tab:

![Allow source to be imported to pipelines.](https://www.palantir.com/docs/resources/foundry/functions/allow-source-to-be-imported-to-pipelines.png)

Once you have enabled this option on your source and published your Python function, it can be used in your pipeline in the same way as any other Python function.  
一旦你在源代码中启用了此选项，并发布了你的 Python 函数，那么就可以像使用其他 Python 函数一样在流程中调用该函数了。
