## Shared ontologies 共享的本体结构

A shared ontology is a special kind of ontology that allows multiple [organizations](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/#organizations) to collaborate on shared workflows. Shared ontologies live under a dedicated shared [space](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/#spaces) created specifically for the workflow. A shared ontology enables resources from multiple organizations to be used in a workflow, whereas an ontology is private to one organization and contains resources from that organization alone.  
共享本体是一种特殊的本体类型，它允许多个组织在共享的工作流程中进行协作。共享本体存在于为特定工作流程而创建的专用共享空间中。通过共享本体，多个组织的资源可以在工作流程中被共同使用；而私有本体则仅属于一个组织，只包含该组织自身的资源。

A shared ontology is automatically created when a new shared space is created. It holds the same organizations [markings](https://www.palantir.com/docs/foundry/security/markings/) and [role grants](https://www.palantir.com/docs/foundry/security/projects-and-roles/#roles) as the shared space.  
当创建一个新的共享空间时，会自动生成一个共享本体。该本体包含与共享空间相同的组织标识和角色权限设置。

See [cross-organization collaboration](https://www.palantir.com/docs/foundry/security/cross-organization-collaboration/) for more details on how to set up secure collaborative workflows.  
有关如何建立安全协作工作流程的更多细节，请参见“跨组织协作”部分。
