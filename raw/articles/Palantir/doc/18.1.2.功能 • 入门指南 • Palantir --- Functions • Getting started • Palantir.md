## Getting started with functions开始使用函数

There are three language options for getting started with functions in Foundry; TypeScript v1, TypeScript v2, and Python. For more information on supported features for each language, review the [language feature support](https://www.palantir.com/docs/foundry/functions/language-feature-support/) specifications.  
在 Foundry 中使用函数时，有三种语言选择可供选择：TypeScript v1、TypeScript v2 以及 Python。如需了解每种语言的支持功能详情，请参考相关语言功能支持说明。

Although each language has a different set of supported features, you will be able to access the same basic platform functionality for each language, including running, testing, and publishing functions. This page provides an overview of these features to help you understand how to use functions repositories, regardless of which language you will be working with.  
虽然每种语言都拥有不同的支持功能，但无论使用哪种语言，你都可以访问相同的基本平台功能，包括运行、测试和发布等操作。本页面概述了这些功能，帮助你了解如何使用功能库，而不管你使用的是哪种语言。

For more detailed instructions on getting started with a specific language, refer to the tutorials below:  
如果您需要关于如何使用某种特定语言的更详细指导，请参考以下的教程：

- [Getting started with TypeScript v1 functions  
	开始使用 TypeScript v1 函数编程](https://www.palantir.com/docs/foundry/functions/typescript-v1-getting-started/)
- [Getting started with TypeScript v2 functions  
	开始使用 TypeScript 2 的函数编程](https://www.palantir.com/docs/foundry/functions/typescript-v2-getting-started/)
- [Getting started with Python functions  
	开始使用 Python 函数](https://www.palantir.com/docs/foundry/functions/python-getting-started/)

Review the sections below for general information on functions repository creation and usage.  
请参考以下章节，以获取有关函数仓库创建和使用的详细信息。

## Create a functions repository创建一个函数仓库。

When creating a functions repository, you will be able to choose the language that best suits your needs. You can initialize functions repositories directly from a project of your choice by selecting **\+ New > Repository**, or from the Code Repositories application by selecting **\+ New repository** in the top right. Once the repository has been initialized, you can add and run functions.  
在创建函数仓库时，你可以选择最适合你需求的语言。你可以从选定的项目直接初始化函数仓库，方法是在应用程序中选择“新建”>“仓库”，或者从“代码仓库”应用中在右上角选择“新建仓库”。一旦仓库被初始化，你就可以添加和运行函数了。

![Create a functions code repository.](https://www.palantir.com/docs/resources/foundry/functions/functions-create-repo.png)

For detailed instructions on how to create a functions repository for a specific language, refer to the tutorial sections below:  
关于如何为特定语言创建函数仓库的详细步骤，请参阅下面的教程部分：

- [Create a TypeScript v1 functions repository  
	创建一个使用 TypeScript v1 编写函数的仓库。](https://www.palantir.com/docs/foundry/functions/typescript-v1-getting-started/#create-a-typescript-v1-functions-repository)
- [Create a TypeScript v2 functions repository  
	创建一个使用 TypeScript 2 编写的函数仓库](https://www.palantir.com/docs/foundry/functions/typescript-v2-getting-started/#create-a-typescript-v2-functions-repository)
- [Create a Python functions repository  
	创建一个用于存放 Python 函数的仓库。](https://www.palantir.com/docs/foundry/functions/python-getting-started/#create-a-python-functions-repository)

## Test in live preview实时预览中的测试过程

The functions live preview allows you to test your functions before committing them to your repository. You can run a function in live preview after adding it to your repository. To do so, open **Functions** on the bottom toolbar and select **Live Preview**. Choose a function, enter input values, and select **Run** to run the function.  
函数实时预览功能允许你在将函数提交到仓库之前进行测试。将函数添加到仓库后，可以打开底部工具栏中的“Functions”选项，选择“实时预览”。然后选择某个函数，输入输入值，再点击“运行”即可执行该函数。

![Run your new function in the functions live preview.](https://www.palantir.com/docs/resources/foundry/functions/tsv2-functions-helper-preview-run.png)

Live preview runs in a different runtime environment than published functions. Differences include CPU resources, available memory, and how long a function can run before timing out.  
实时预览在运行时环境上与已发布的函数有所不同。这些差异包括 CPU 资源、可用内存，以及函数在超时之前可以运行的时间长度。  
  
[Manage the runtime environment for published functions.  
管理已发布函数的运行环境。](https://www.palantir.com/docs/foundry/functions/manage-functions/)

Select **Commit** in the upper right to commit your changes to the `master` branch of your repository.  
在右上角选择“提交”按钮，将你的更改提交到仓库的 `master` 分支上。

## Publish your functions 发布你的函数吧。

Once you commit your work, you will see the option to **Tag version**. This will publish all of the functions in your repository to the functions registry, [making them accessible across the platform](https://www.palantir.com/docs/foundry/functions/use-functions/).  
一旦你提交了你的工作，你会看到“标记版本”的选项。这将使得仓库中的所有功能被发布到函数注册表中，从而使这些功能能够在整个平台上被访问到。

![The "Tag version" option.](https://www.palantir.com/docs/resources/foundry/functions/ts-functions-tags.png)

Select **Tag version** to tag a release off of the `master` branch. Set the tag name based on the extent of your changes, then choose **Tag and release**.  
选择标签版本，以将版本标记为脱离 `master` 分支的版本。根据您的修改程度来设定标签名称，然后选择“标签”并发布该版本。

![Choose the version type to tag for the new release.](https://www.palantir.com/docs/resources/foundry/functions/new-tag.png?width=500)

To view progress as your functions are tagged and released, select the **View** pop-up or navigate to the **Tags** tab. Once **Step 2: Release** is completed, select the published functions to view them in the functions registry.  
在您的功能被标记并准备发布时，可以查看相关进度。可以选择“查看弹出窗口”选项，或者前往“标签”选项卡。当“步骤 2：发布”完成之后，可以选择已发布的功能，以便在功能注册表中查看它们。

Functions may not be immediately searchable by name in Workshop or the functions registry while permissions propagate.  
在权限生效期间，用户无法通过名称直接查找某个函数或函数在函数注册表中对应的位置。

![Both the tag and release checks passed, and the new function is published.](https://www.palantir.com/docs/resources/foundry/functions/tsv1-functions-tags-and-releases.png)

## Run your function 运行你的函数吧。

After the checks for your tag have passed, navigate back to the **Code** tab in Code Repositories and select **Functions** from the bottom toolbar. You should see your new function under the **Published** section. Select it, and try running the new function:  
在检查完标签的相关内容后，返回“代码仓库”中的“代码”选项卡，然后从底部工具栏中选择“函数”选项。你应该会在“已发布”部分看到新创建的函数。点击该函数，尝试运行这个新函数。

![Run the new function in the functions helper.](https://www.palantir.com/docs/resources/foundry/functions/tsv1-functions-helper-run.png)

了解更多关于如何在整个平台上运用各种功能的信息。](https://www.palantir.com/docs/foundry/functions/use-functions/)
