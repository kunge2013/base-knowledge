## Use actions in the platform

Action types can be seamlessly integrated across applications in Foundry. Read on to learn how to configure and apply an action from [Object Explorer](https://www.palantir.com/docs/foundry/object-explorer/overview/) and [Workshop](https://www.palantir.com/docs/foundry/workshop/overview/).

In the examples below, we use the term **single action type** to refer to an action type using an object reference parameter, and **bulk action type** to refer to an action using an object reference list parameter.

## Object views

Actions can be added to an [Object View](https://www.palantir.com/docs/foundry/object-views/overview/) using the **Actions section**.

![The Actions section of the Object View](https://www.palantir.com/docs/resources/foundry/action-types/integrate_actions_object_explorer_object_view_actions_section.png)

When configuring the **Actions section** you have the option to:

- Add any action as a button in the section.
- Give each button its own label and color.
- Change the default on-click behavior from opening the form to applying the action immediately using the default values (if valid).
- Specify whether the button should be hidden or disabled if a non-visible parameter is invalid (the idea being that visible parameters could be corrected upon opening the form).
- Provide a default value for each parameter; this can be a property value of the current object or a "local" value (current user, current timestamp, current object, or a manually entered value).
- Override the visibility of each parameter.

As shown above, you can therefore use this section to offer multiple structured versions of the same generic action ("Delay 10 minutes", "Delay 30 minutes", etc.).

## Object Explorer 对象浏览器

Actions will automatically be shown in three places across [Object Explorer](https://www.palantir.com/docs/foundry/object-explorer/overview/):

1. From the **Actions** dropdown in the Exploration View (top right).

![The Actions dropdown in the Exploration View](https://www.palantir.com/docs/resources/foundry/action-types/integrate_actions_object_explorer_exploration_view_actions_dropdown.png)

Using the current set of objects, this dropdown is automatically populated with applicable bulk actions.

2. From the **Object Actions** dropdown menu in the Object View (top right).

![The Object Actions dropdown in the Object View](https://www.palantir.com/docs/resources/foundry/action-types/integrate_actions_object_explorer_object_view_object_actions_dropdown.png)

Using the current object, this dropdown menu is automatically populated with applicable single and bulk action types.  
使用当前对象时，该下拉菜单会自动填充适用的单一操作类型以及批量操作类型。

3. From the **Linked objects view section** in the Object View (top).  
	在对象视图中的“链接对象”视图部分（顶部）。

![The Linked objects view section in the Object View](https://www.palantir.com/docs/resources/foundry/action-types/integrate_actions_object_explorer_object_view_linked_objects_view_section.png)

Using the selected object(s), this dropdown is automatically populated with applicable single and/or bulk action types.

In "bulk" contexts (where multiple objects are shown in a list view), only actions that accept object list parameters of the correct type will be shown.

## Workshop 研讨会

In [Workshop](https://www.palantir.com/docs/foundry/workshop/overview/), Actions can be configured and applied using the [**Button group** widget](https://www.palantir.com/docs/foundry/workshop/widgets-button-group/).

![Button group widget in Workshop](https://www.palantir.com/docs/resources/foundry/action-types/integrate_actions_workshop_button_group_widget.png)

This widget has the same configuration options as the [Actions section](#object-views) in an Object View, with a few notable extensions:  
这个小工具具有与“对象视图”中的“操作”部分相同的配置选项，但有一些额外的功能：

- There are three possible layouts, all of which are shown above.  
	有三种可能的布局方式，以上都已经展示过了。
- The buttons have additional display options, including left/right icons, minimal styles, and tag styles.  
	这些按钮还提供了额外的显示选项，包括左右箭头图标、简洁样式以及带有标签的样式。
- In addition to an Action, an individual button can trigger a Workshop event, URL, or object set export.  
	除了“动作”功能之外，每个单独的按钮还可以触发研讨会事件、URL 调用，或者对象集导出操作。

And one difference:还有一个区别：

- A default value can be a [variable](https://www.palantir.com/docs/foundry/workshop/concepts-variables/), the current user, or the current timestamp  
	默认值可以是一个变量、当前用户，或者当前的时间戳。

Read more about [Actions in Workshop](https://www.palantir.com/docs/foundry/workshop/actions-overview/), or read the full reference for the [Button Group widget](https://www.palantir.com/docs/foundry/workshop/widgets-button-group/) to learn about all available configuration options.  
更多关于“工作区中的操作”的信息，或者可以阅读完整的参考文档以了解按钮组小部件的所有可用配置选项。
