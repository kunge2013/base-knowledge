## Derived properties \[Beta\]派生属性 \[测试版\]

Beta

Derived properties are in the [beta](https://www.palantir.com/docs/foundry/platform-overview/development-life-cycle/) phase of development and may not be available on your enrollment. Functionality may change during active development.  
这些衍生属性目前处于开发测试阶段，可能在您注册后无法使用。在持续开发过程中，其功能可能会发生变化。

Derived properties are properties that are calculated at runtime based on the values of other properties or links on objects. This includes aggregating on or selecting properties of linked objects. Derived properties are then available for further operations, such as filtering, sorting, or aggregating within the same request. Derived properties use the security of all objects involved in the calculation, so they do not expose information a user would otherwise be unable to see.  
派生属性是指那些在运行时根据对象其他属性或链接的值来计算得出的属性。这意味着可以针对链接到的对象进行属性聚合或选择操作。派生属性可以用于进一步的操作，比如过滤、排序或在同一请求中执行聚合操作。由于派生属性利用了参与计算的所有对象的安全性信息，因此它们不会泄露用户无法看到的信息。

## Availability 可用性

Derived properties are available in the following workflows:  
以下工作流程中提供了派生属性：

- **Ontology SDK:** Derived properties can be used in the TypeScript OSDK with the `withProperties` operation, to be returned or used in additional filters, aggregations, or sorts. The TypeScript OSDK must be running the `2.2.0-beta.x` version of the `@osdk/client` package or later. Review the API documentation in [Developer Console](https://www.palantir.com/docs/foundry/developer-console/overview/) for more details.  
	Ontology SDK：在 TypeScript OSDK 中，可以使用 `withProperties` 操作来访问派生属性，这些属性可以用于返回结果，或者作为其他过滤、聚合或排序操作的参数。确保 TypeScript OSDK 运行在 `@osdk/client` 包的最新版本或更高版本之上。更多详细信息请参考开发者控制台中的 API 文档。

## Known limitations 已知的局限性

As a beta feature under active development, derived properties currently have some capability limitations. Many of these capabilities will become available over time as additional functionality is built. Current limitations are listed below:  
作为一项正在积极开发的测试功能，目前派生属性存在一些功能限制。随着后续功能的不断完善，这些限制将会逐渐得到解决。当前的限制如下：

- **OSv1 support:** Queries with derived properties may not contain any object types indexed using [OSv1](https://www.palantir.com/docs/foundry/object-backend/osv1-osv2-migration/).  
	OSv1 支持：包含派生属性的查询中可能不包含任何使用 OSv1 索引的对象类型。
- **Text search:** Derived properties cannot be used in text search or keyword filters.  
	文本搜索：派生属性无法用于文本搜索或关键词过滤器中。
- **Structs in OSDK:** Specifically in current versions of the Typescript OSDK, queries with derived properties may not contain any [struct](https://www.palantir.com/docs/foundry/object-link-types/structs-overview/) property types. You can use a `$select` operation in Ontology SDK to exclude struct properties.  
	在 OSDK 中，结构体存在以下限制：在当前的 TypeScript OSDK 版本中，包含派生属性的查询可能无法包含任何结构体属性类型。在 Ontology SDK 中，可以使用 `$select` 操作来排除结构体属性。
- **Marketplace:** Functions using derived properties are not currently supported in Marketplace.  
	市场平台：目前，市场平台不支持使用派生属性进行功能实现。
