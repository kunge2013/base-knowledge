## Struct properties and shared property types结构属性与共享属性类型

Struct properties can be used by local and shared property types. When converting, or promoting a local property type to a shared property type, struct fields need to be re-mapped. Local struct property types backed by shared property types will inherit shared property type fields except for the struct field resource identifiers (RIDs). Struct field metadata (display name, description, aliases) will then be inherited from the shared property type, but struct fields with keep their original RIDs.  
结构体属性可以同时使用局部属性和共享属性类型。在将局部属性类型转换为共享属性类型时，需要重新映射结构体中的字段。由共享属性类型支持的局部结构体属性类型会继承共享属性类型的字段，除了结构体字段的标识符（RIDs）之外。结构体的字段元数据（显示名称、描述、别名等）则会从共享属性类型继承过来，但具有保留原始 RIDs 的结构体字段仍然保持原样。

## Create a struct type shared property创建一个结构体类型，并为其定义一个共享属性。

1. In Ontology Manager, you can create a struct type shared property in two ways:  
	在 Ontology Manager 中，你可以以两种方式创建结构类型共享属性：
	- From the top right of the homepage, select **New > Shared property** ![Shared property option from the New dropdown menu.](https://www.palantir.com/docs/resources/foundry/object-link-types/new-dropdown-menu-shared-property.png?width=300)在首页的右上角，选择“新建”>“共享财产” ![Shared property option from the New dropdown menu.](https://www.palantir.com/docs/resources/foundry/object-link-types/new-dropdown-menu-shared-property.png?width=300)
		- Select **Shared properties > + New shared property** ![+ New shared property option in the Shared properties tab.](https://www.palantir.com/docs/resources/foundry/object-link-types/new-shared-property-button.png?width=500)选择“共享属性”>“新建共享属性” ![+ New shared property option in the Shared properties tab.](https://www.palantir.com/docs/resources/foundry/object-link-types/new-shared-property-button.png?width=500)
2. In the main panel, select the **New shared property** button. This will open a helper where you can configure metadata of the shared property including the name, description, aliases, and API name. Then select **Next** to proceed.  
	在主面板中，选择“新建共享属性”按钮。这将打开一个界面，你可以在其中配置共享属性的元数据，包括名称、描述、别名以及 API 名称。然后选择“下一步”以继续操作。
	![The 'Create shared property' dialog.](https://www.palantir.com/docs/resources/foundry/object-link-types/create-shared-property-modal.png?width=500)
3. Configure the base type, value type, visibility, and whether to require values for the property.  
	配置基础类型、值类型、可见性，以及该属性是否需要接受值。
	![Create shared property window on the configuration step.](https://www.palantir.com/docs/resources/foundry/object-link-types/create-shared-property-configuration.png?width=500)
4. Select a project to save this shared property to.  
	请选择一个项目来保存这个共享属性。
	![Select save location for the shared property.](https://www.palantir.com/docs/resources/foundry/object-link-types/create-shared-property-save-location.png?width=500)
5. Back in Ontology Manager, select **Save** in the upper right corner to [make the change to your ontology](https://www.palantir.com/docs/foundry/ontology-manager/save-changes/).  
	在 Ontology Manager 中，点击右上角的“保存”按钮，即可对您的本体进行更新。

## Attach a struct type shared property附加一个结构类型的共享属性

1. In Ontology Manager, open the **Properties** tab and select the desired property from the **Properties** table.  
	在 Ontology Manager 中，打开“属性”选项卡，然后从属性表中选择所需的属性。
2. In the **Property editor** to the right, scroll down to **Shared property** and select a shared property under **Assign**. This will share property metadata among both properties.  
	在右侧的属性编辑器中，向下滚动到“共享属性”部分，然后选择“分配”下的共享属性。这样就能在这两个属性之间共享属性元数据了。
![The shared property dropdown in the Assign section.](https://www.palantir.com/docs/resources/foundry/object-link-types/spt-attachment.png?width=500)

**Note:** To add new struct fields after assigning a shared property type to a local struct property type, you must add the new struct fields to the shared property type and map them to datasource columns for all local struct property types that are backed by the shared property.  
注意：在将一个共享属性类型分配给局部结构体属性类型之后，要添加新的结构体字段，需要将这些新字段添加到共享属性类型中，并映射到所有由共享属性支持的局部结构体属性类型的数据源列上。

## Convert a struct property type into a shared property将结构体属性类型转换为共享属性。

The following instructions detail how to convert a struct property into a struct property backed by a shared property type.  
以下说明详细介绍了如何将结构体的属性转换为由共享属性类型支持的属性。

1. In Ontology Manager, open the **Properties** tab and select the desired property from the **Properties** table.  
	在 Ontology Manager 中，打开“属性”选项卡，然后从属性表中选择所需的属性。
2. In the **Property editor** to the right, scroll down and select **Convert to a shared property**, which backs the struct property by a shared property type.  
	在右侧的属性编辑器中，向下滚动并选择“转换为共享属性”，这样就能将结构属性转换为共享属性类型，从而增强其支持度。
![The 'Convert to a shared property' button in the Property editor.](https://www.palantir.com/docs/resources/foundry/object-link-types/spt-convert.png?width=500)
