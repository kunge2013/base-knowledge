## Create a value type创建一种价值类型。

Follow the steps below to create a value type to use across your platform [space](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/#spaces).  
按照以下步骤来创建一个可以在各个平台之间使用的价值类型。

1. Navigate to the **Value Types Manager** application from the platform sidebar.  
	从平台侧边栏中导航到“值类型管理器”应用程序。
2. From the top left corner, use the dropdown menu to select the space in which you would like to create a value type.  
	从左上角开始，通过下拉菜单选择您想要创建数值类型的空间。
3. Select **Create New Value Type** from the upper right corner.  
	从右上角选择“创建新值类型”。
4. Provide a clear name, description, and unique API name for your value type.  
	请为你的价值类型提供一个清晰的名称、描述，以及唯一的 API 名称。
![Value type metadata creation](https://www.palantir.com/docs/resources/foundry/object-link-types/value-type-create-metadata.png?width=500)
5. Choose a [base type](https://www.palantir.com/docs/foundry/object-link-types/base-types/) for your value type.  
	为你的价值类型选择一个基础类型。
6. (Optional) Define a constraint for your value type. Validators can be regular expressions for `String` types, enums, ranges, or other validation methods depending on the base type. For a full list of constraints supported by base type, review our [value type constraints](https://www.palantir.com/docs/foundry/object-link-types/value-type-constraints/) documentation.  
	（可选）为你的值类型定义约束条件。验证工具可以是正则表达式、枚举值、范围，或者根据基础类型采用其他验证方式。如需了解基础类型支持的所有约束条件，请参考我们的值类型约束文档。
![Value type constraint creation](https://www.palantir.com/docs/resources/foundry/object-link-types/value-type-create-constraint.png?width=500)
7. (Optional but recommended) Provide an example preview value for your value type.  
	（可选，但建议提供）为你的价值类型提供一个示例预览值。
![Value type preview creation](https://www.palantir.com/docs/resources/foundry/object-link-types/value-type-create-preview.png?width=500)
8. Save your value type.  
	请保存你的价值类型。
