## Base types 基础类型

Property base types define the kind of data that can be stored in a property. For a complete reference of all supported property base types, see the [properties overview](https://www.palantir.com/docs/foundry/object-link-types/properties-overview//#supported-property-types).  
属性基础类型定义了可以存储在其中的数据类型。如需了解所有支持的属性基础类型的完整列表，请参见属性概述部分。

**Base types** are used to define properties on objects. The base type of a property determines the set of operations available for that property in user applications. All field types are valid base types except for `Map` and `Binary` types.  
基础类型用于定义对象的属性。某个属性的基础类型决定了用户在应用程序中对该属性进行操作时可用的操作集。除了 `Map` 和 `Binary` 类型之外，所有字段类型都是有效的基础类型。

Base types also include the following advanced types:  
基础类型还包括以下高级类型：

- **Vector:** A type for storing [vectors](https://www.palantir.com/docs/foundry/announcements/2023-11/#configure-a-vector-property-type) on objects for use in a semantic search.  
	向量：一种用于在对象上存储向量的类型，以便于进行语义搜索。
- **`Geopoint`:** A type for defining properties that represent geographic [points](https://www.palantir.com/docs/foundry/geospatial/ontology/#points).  
	`Geopoint` ：这是一种用于定义表示地理点的属性的类型。
- **`Geoshape`:** A type for defining properties that represent geographic [shapes](https://www.palantir.com/docs/foundry/geospatial/ontology/#polygons-and-lines).  
	`Geoshape` ：一种用于定义表示地理形状的属性的类型。
- **Attachment:** A type for storing files on objects for use with [functions on objects](https://www.palantir.com/docs/foundry/functions/attachments/).  
	附件：一种用于在对象上存储文件的类型，这些文件可以与对象的函数一起使用。
- **Time series:** A type for defining a property as a [time series](https://www.palantir.com/docs/foundry/time-series/time-series-overview/).  
	时间序列：一种用于描述属性为时间序列的类型。
- **Geotemporal series:** A type for defining a property as a reference to a [geotemporal series](https://www.palantir.com/docs/foundry/geospatial/geotemporal-series-overview/).  
	地理时间序列：一种用于定义属性类型的方式，该属性指的是对地理时间序列的引用。
- **Media reference:** A type for defining a [reference to a media file](https://www.palantir.com/docs/foundry/media-sets-advanced-formats/media-overview/#media-references).  
	媒体引用：一种用于指代媒体文件的引用方式。
- **Cipher text:** A type for storing a string value encoded with [Cipher](https://www.palantir.com/docs/foundry/cipher/overview/).  
	密文：一种用于存储经过加密处理的字符串值的格式。
- **Struct:** A type for defining schema-based properties with [multiple fields](https://www.palantir.com/docs/foundry/object-link-types/structs-overview/).  
	结构：一种用于定义包含多个字段的基于模式的属性的类型。

All base types may be used in arrays to represent multiple values for a property, excluding the `Vector` and `Time series` types.  
所有基础类型都可以用于数组中来表示某个属性的多个值，不过 `Vector` 和 `Time series` 类型除外。

Some property base types require additional configuration or have specific use cases. Refer to the sections below for information on the following property base types:  
某些属性基础类型需要额外的配置或具有特定的使用场景。有关这些属性基础类型的详细信息，请参考以下章节：

	结构类型：包含多个字段的复杂结构化数据。

### Media references 媒体引用

A **media reference** property type allows you to have media on your objects, such as images, videos, audio files, and documents. A [media reference](https://www.palantir.com/docs/foundry/media-sets-advanced-formats/media-overview/#media-references) points to a specific media item within a [media set](https://www.palantir.com/docs/foundry/data-integration/media-sets/). The media reference contains information about the media file, which means Foundry can display the media wherever the media reference is used.  
媒体引用属性类型允许您在对象中包含媒体内容，例如图片、视频、音频文件等。媒体引用指的是媒体集中的特定媒体项。媒体引用包含了关于媒体文件的信息，这意味着在使用媒体引用时，Foundry 可以随意展示这些媒体内容。

#### Media reference format 媒体引用格式

Below is an example media reference:  
以下是媒体引用示例：

```json
Copied!{
  "mimeType": "image/png",
  "reference": {
    "type": "mediaSetViewItem",
    "mediaSetViewItem": {
      "mediaSetRid": "ri.mio.main.media-set.00000000-0000-0000-0000-00000000000",
      "mediaSetViewRid": "ri.mio.main.view.00000000-0000-0000-0000-00000000000",
      "mediaItemRid": "ri.mio.main.media-item.00000000-0000-0000-0000-00000000000"
    }
  }
}
```

The media reference includes the following:  
媒体引用中包含了以下内容：

- **`mimeType`:** The file's media type.  
	`mimeType` ：该文件的媒体类型。
- **`reference`:** A reference containing the media set RID, view RID, and specific media item RID.  
	`reference` ：这是一个包含媒体集 RID、视图 RID 以及特定媒体项 RID 的引用。

#### Configure media reference properties配置媒体引用属性。

Object types with media reference properties are backed by a dataset. The backing dataset must include a media reference column, which will map to the media reference property. This column type is specifically designed to store media reference values and ensures proper integration between your ontology objects and media sets.  
具有媒体引用属性的对象类型是由某个数据集支持的。该数据集必须包含一个名为“媒体引用”的列，这个列会映射到媒体引用属性上。这种列类型旨在用于存储媒体引用信息，从而确保你的本体对象与媒体集之间的正确集成。

![A media reference property's source.](https://www.palantir.com/docs/resources/foundry/object-link-types/media-reference-source.png)

Additionally, a media reference property must have a **media source**, which can be configured in the **Capabilities** tab of the object type. This media source should be the media set that the media references point to.  
此外，一个媒体引用属性必须包含一个媒体源，该媒体源可以在对象类型的“能力”选项卡中进行配置。这个媒体源应该是媒体引用所指向的媒体集。

![Media reference properties in the "Capabilities" tab.](https://www.palantir.com/docs/resources/foundry/object-link-types/media-reference-media-source.png)

### Structs 结构/框架

A **struct** is an ontology property base type that allows users to create schema-based properties with multiple fields. Struct properties are created from struct type dataset columns. To learn more about structs, refer to the complete [struct](https://www.palantir.com/docs/foundry/object-link-types/structs-overview/) documentation.  
结构是一种本体属性基础类型，它允许用户创建包含多个字段的基于模式的属性。结构属性是从结构类型的数据集列中生成的。想要了解更多关于结构的信息，请参考完整的结构文档。
