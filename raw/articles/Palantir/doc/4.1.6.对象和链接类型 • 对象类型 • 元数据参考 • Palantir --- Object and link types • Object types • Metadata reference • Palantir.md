## Metadata reference 元数据参考

An object type is represented in the Ontology by the following metadata:  
在本体中，一个对象类型由以下元数据表示：

- **ID:** A unique identifier of the object type, primarily used to reference objects of this type when configuring an application. For example, `employee` may be the ID of the `Employee` object type.  
	ID：这是一种唯一的对象标识符，主要用于在配置应用程序时引用此类对象。例如， `employee` 可能是 `Employee` 对象类型的 ID。
- **RID:** An automatically generated unique identifier for every resource in Foundry. An object type’s RID will be referenced in error messages across the platform.  
	RID：这是 Foundry 为每个资源自动生成的唯一标识符。在某个平台上，当出现错误时，会引用某个对象的 RID 来进行标识。
- **Icon:** A picture and color used as a visual identifier of the object type that will appear in user applications when a user views an object of this type. For example, the person icon may be used to depict the `Employee` object type.  
	图标：一种图片和颜色组合，用作在用户界面中显示某种对象时的视觉标识。例如，人物图标可以用来表示 `Employee` 那种对象类型。
- **Display name:** The name shown to anyone accessing an object of this type in user applications. For example, the display name for the `Employee` object type may be `Employee`.  
	显示名称：这是用户在访问此类对象时看到的名称。例如， `Employee` 对象类型的显示名称可能是 `Employee` 。
- **Plural display name:** The name shown to anyone accessing multiple objects of this type in user applications. For example, the plural display name for the `Employee` object type may be `Employees`.  
	复数形式显示名称：在用户应用程序中，用于显示访问多个此类对象时的名称。例如， `Employee` 对象类型的复数显示名称可能是 `Employees` 。
- **Description:** Explanatory text about the object type that anyone can read in user applications. For example, the description of the `Employee` object type may be `All full-time and part-time employees of Organization X`.  
	描述：关于该对象类型的解释性文本，用户应用程序可以轻松阅读。例如， `Employee` 对象类型的描述可能是 `All full-time and part-time employees of Organization X` 。
- **Groups:** A group is a label that helps you categorize your object types. For example, the `Employee` object type may belong to groups `HR` and `Employee 360`.  
	组：组是一个标签，用于帮助你对对象类型进行分类。例如， `Employee` 对象类型可能属于 `HR` 和 `Employee 360` 这两个组。
- **API name:** The name used when referring to the object type programmatically in code. For example, the API name of the `Employee` object type may be `Employee`. Read more about [API names](https://www.palantir.com/docs/foundry/functions/api-objects-links/).  
	API 名称：这是在代码中程序化地引用对象类型时所使用的名称。例如， `Employee` 对象类型的 API 名称可能是 `Employee` 。更多关于 API 名称的信息请参考相关文档。
- **Visibility:** An indication to user applications for how prominently to display the object type. A `prominent` object type will lead applications to show this object type first to users. A `hidden` object type will not appear in user applications. By default, the `Employee` object type will have visibility `normal`.  
	可见性：用于指示用户应用程序该如何突出显示该对象类型。 `prominent` 对象类型会让应用程序首先向用户展示该对象类型。而 `hidden` 对象类型则不会出现在用户应用程序中。默认情况下， `Employee` 对象类型的可见性为 `normal` 。
- **Status:** A signal to users and other Ontology builders about where in the development process the object type stands. It can be `active`, `experimental`, or `deprecated`. By default, the `Employee` object type will have status `experimental`. Read more about [statuses](https://www.palantir.com/docs/foundry/object-link-types/metadata-statuses/).  
	状态：这是一个向用户和其他 Ontology 构建者提供的信号，表明该对象类型在开发过程中所处的阶段。该状态可以是 `active` 、 `experimental` 或 `deprecated` 。默认情况下， `Employee` 对象类型的状态为 `experimental` 。有关状态的更多信息，请阅读相关说明。
- **Index status:** The status of the last reindex of the object type and its backing datasources. It can be `success`, `failed`, or `not started`. Read more about [index statuses](https://www.palantir.com/docs/foundry/object-databases/object-storage-v1/).  
	索引状态：指该对象类型及其支持的数据源在最后一次重新索引时的状态。该状态可以是 `success` 、 `failed` 或 `not started` 。关于索引状态的更多信息，请参考相关说明。
- **Writeback:** An indication of whether the object type has a writeback dataset generated, and whether allowing end users to make edits to objects of this type is `enabled` or `disabled`. Read more about [writeback datasets](https://www.palantir.com/docs/foundry/object-link-types/allow-editing/).  
	写入回执：该字段用于指示该对象类型是否生成了写入回执的数据集，以及是否允许终端用户对这类对象进行编辑。更多关于写入回执数据集的信息请参见 `enabled` 或 `disabled` 。
