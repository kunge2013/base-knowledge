## Struct main fields \[Beta\]结构化主要领域 \[测试版\]

Beta

Struct main fields are in the [beta](https://www.palantir.com/docs/foundry/platform-overview/development-life-cycle/) phase of development and may not be available on your enrollment. Functionality may change during active development.  
这些主要功能目前处于开发测试阶段，可能在您注册时尚未上线。在持续开发过程中，其功能可能会发生变化。

**Struct main fields** enable you to designate a [struct's](https://www.palantir.com/docs/foundry/object-link-types/structs-overview/) core value and supplementary metadata. For example, an `Address` struct may contain fields capturing `streetName` and `postalCode` as its main values, while other fields like `collectionDate` and `collectorName` represent metadata that describe how the `Address` was obtained.  
结构体中的主字段允许你指定结构的核心值和附加元数据。例如，一个 `Address` 结构体可能包含 `streetName` 和 `postalCode` 作为其核心值，而像 `collectionDate` 和 `collectorName` 这样的字段则代表用于描述如何获取 `Address` 的元数据。

Many struct properties follow this pattern: one or more fields contain the primary data you care most about displaying in applications, while other fields provide context, tracking information, or audit details.  
许多结构化数据的属性都遵循这种模式：一个或多个字段包含了在应用中最值得展示的主要数据，而其他字段则提供了上下文信息、跟踪数据或审计相关细节。

You can designate any of the [supported struct field types](https://www.palantir.com/docs/foundry/object-link-types/structs-overview/#struct-configuration) as main fields.  
你可以将任何支持的结构体字段类型指定为主要字段。

## When to use struct main fields何时使用 struct、main 以及 fields

Use struct main fields when:  
在以下情况下使用\`struct main fields\`：

- Your struct contains core value fields in addition to fields that represent supplementary metadata.  
	你的结构体除了包含表示补充元数据的字段之外，还包含了核心价值相关的字段。
- You want cleaner table displays without losing access to metadata.  
	您希望表格的显示更清晰，同时又不失去对元数据的访问权限。
- You need to [implement interfaces](https://www.palantir.com/docs/foundry/interfaces/implement-interface/) using only a single field or subset of fields from a struct.  
	你需要仅通过使用结构体中的一个或多个字段来实现接口。

## Configure struct main fields配置 main 结构的字段

1. Navigate to **Ontology Manager**.  
	请前往 Ontology Manager 界面。
2. Search for and select your object type by choosing **Object types** under **Resources** in the left panel.  
	在左侧面板中的“资源”选项中，选择“对象类型”，然后搜索并选择你需要的对象类型。
3. Select the struct property to configure from your object type's **Properties** tab.  
	从对象的属性页面中选择想要配置的结构体属性。
4. Choose the field to designate from the **Struct fields** section of the **General** tab that appears in the property editor panel on the right.  
	在右侧属性编辑器面板中“General”选项卡下的“Struct 字段”部分，选择要指定的字段。
![Main fields configuration location](https://www.palantir.com/docs/resources/foundry/object-link-types/struct-main-fields-sidebar-location.png?width=400)
5. Toggle on **Struct main field** in the **Edit {propertyName} struct field** popup window before you select **Confirm**. You can designate multiple main fields and reorder them for clarity by clicking and dragging a field's panel.  
	在选择“确认”选项之前，请先打开“编辑{propertyName}结构”窗口中的主字段选项。你可以选择多个主字段，并通过点击并拖动某个字段的面板来重新排序这些字段，以便更好地组织内容。
![Struct main field toggle](https://www.palantir.com/docs/resources/foundry/object-link-types/struct-main-fields-toggle.png?width=450)
6. **Save** your changes. Configured main fields display a **Struct main field** tag in the **Struct fields** list.  
	请保存您的更改。现在，配置好的主要字段在结构体字段列表中会显示“Struct main field”标签。
![Struct main field tags](https://www.palantir.com/docs/resources/foundry/object-link-types/struct-main-fields-tags.png?width=400)

## How struct main fields appear in applications各种应用领域中，主要字段的呈现方式是怎样的？

Applications that support struct main fields display only the main fields in compact views, like the [Object Table](https://www.palantir.com/docs/foundry/workshop/widgets-object-table/) and [Object List](https://www.palantir.com/docs/foundry/workshop/widgets-object-list/) widgets in [Workshop](https://www.palantir.com/docs/foundry/workshop/overview/), while providing access to the full struct through an expanded view or upon hover. This enables you to quickly scan the most important data without seeing every struct field, while still being able to inspect the complete struct when needed.  
那些支持结构体主字段的应用程序会仅以简洁的视图形式展示主字段，比如 Workshop 中的对象表和对象列表控件。同时，用户也可以通过展开视图或悬停鼠标来查看整个结构体。这样，用户可以快速浏览最重要的数据，而不需要查看每一个结构体字段。不过，在需要的时候，用户仍然可以查看整个结构体。

Applications support struct main fields in several ways:  
应用程序以多种方式支持主字段的结构化存储：

- **Main fields only:** Display only main fields in compact views like tables or summary cards.  
	仅显示主要字段：在表格或摘要卡片等简洁视图中，只显示主要字段。
- **Main fields with hover:** Show main fields by default and reveal metadata fields on hover.  
	鼠标悬停在主要字段上时显示的内容：默认情况下，鼠标悬停在某个字段上时会显示该字段的内容，同时还会显示相关的元数据信息。
- **Full struct:** Display all fields in detailed views or forms where complete information is needed.  
	完整结构：在需要完整信息的详细视图或表单中显示所有字段。

## Use struct fields with interfaces在接口中使用结构体字段

You can map any struct field to an interface property. When implementing an interface, you can select a specific field from a struct property to satisfy the interface contract and fulfill the property requirement.  
你可以将任何结构体字段映射到接口属性上。在实现接口时，可以选择结构体中的某个特定字段来满足接口的要求，从而满足属性需求。

For example, if an interface requires a `String` property called `cityName`, you can fulfill it using a struct property's `city` field. The interface picker displays all available struct fields with their types, allowing you to choose the appropriate field.  
例如，如果某个接口需要一个名为 `cityName` 的 `String` 属性，你可以使用结构体属性的 `city` 字段来满足这一需求。接口选择界面会显示所有可用的结构体字段及其类型，这样你就可以选择合适的字段了。

![Selecting a struct field to map to an interface property](https://www.palantir.com/docs/resources/foundry/object-link-types/struct-main-fields-interface-picker.png?width=700)

After mapping a struct field to an interface property, the implementation shows the struct property and the specific field being used.  
在将结构体字段映射到接口属性之后，实现部分会展示该结构体属性以及所使用的具体字段。

![Mapped struct field to interface property](https://www.palantir.com/docs/resources/foundry/object-link-types/struct-main-fields-interface-mapped.png?width=700)

Main fields are indicated with a **Struct main field** tag in the picker, making them easy to identify. However, you can select any field from the struct regardless of whether it is designated as a main field.  
在选择器中，主要字段会用“Struct main field”标签进行标识，因此很容易识别。不过，你可以选择结构体中的任何字段，无需考虑该字段是否被指定为主要字段。

## Combine main fields with property reducers将主要字段与属性缩减器结合使用

Combine struct main fields with [property reducers](https://www.palantir.com/docs/foundry/object-link-types/property-reducers/) to enable additional flexibility in struct array property representation and interface implementation. A single struct array property can implement interfaces requiring `Struct Array`, the main field's array type, `Struct`, or the main field's base type.  
通过将结构体中的主字段与属性缩减器相结合，可以在结构体数组的属性表示和接口实现上实现更大的灵活性。一个结构体数组的属性可以实现需要 `Struct Array` 、主字段的数组类型，或者主字段的基础类型的接口。

See the [property reducers documentation](https://www.palantir.com/docs/foundry/object-link-types/property-reducers/#combine-property-reducers-with-struct-main-fields) for detailed examples and implementation options.  
请参阅房产减价活动的相关文档，其中包含了详细的示例和实现选项。

## Limitations and considerations限制与考量

- **Query behavior:** Queries operate on all struct fields, not just main fields. You can search and filter based on any field in the struct.  
	查询行为：查询操作适用于结构体中的所有字段，而不仅仅是主字段。你可以根据结构体中的任何字段进行搜索和筛选。

## FAQs 常见问题解答

### Can I change which fields are main fields later?之后我可以更改哪些字段被视为主字段吗？

Yes, you can reconfigure main fields in Ontology Manager at any time. This may render some interface implementations invalid, which you will need to update.  
是的，您可以随时重新配置 Ontology Manager 中的主要字段。这可能会导致某些界面实现变得无效，您需要对其进行更新以使其恢复正常。

### Do main fields affect how Foundry stores data?主要字段是否会影响 Foundry 存储数据的方式？

No, main fields only affect how Foundry displays data and implements interfaces. The underlying struct contains all fields with full fidelity, so all fields remain queryable and accessible.  
不，这些主要字段只会影响 Foundry 软件对数据的展示方式以及接口的实现。而底层的结构体中包含了所有字段的完整信息，因此所有字段仍然可以被查询和访问到。

### Can I use main fields with struct arrays?我可以使用结构体数组来操作主字段吗？

Yes. Main fields work with *both* single struct properties and struct array properties. When combined with [reducers](https://www.palantir.com/docs/foundry/object-link-types/property-reducers/), you get maximum flexibility in how Foundry represents the property across applications.  
是的。主要字段可以处理单个结构体属性以及结构体数组属性。当与 reducer 结合使用时，可以在各种应用中灵活地使用 Foundry 来表示这些属性。

### Do I need to configure main fields to use struct fields with interfaces?我需要使用结构体字段与接口一起使用吗？是否需要配置一些主要字段呢？

No. You can map any struct field to an interface property regardless of whether it is designated as a main field. Main fields simply provide a visual indicator in the interface picker and affect how applications display the struct in compact views.  
是的，你可以将任何结构体字段映射到一个接口属性上，无论该字段是否被指定为主要字段。主要字段只是在接口选择器中提供了一个视觉指示，并且决定了应用程序在紧凑视图中如何展示结构体。
