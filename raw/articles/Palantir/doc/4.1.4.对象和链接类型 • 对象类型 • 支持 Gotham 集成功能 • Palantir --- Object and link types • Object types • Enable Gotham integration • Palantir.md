Note 注意：

If your enrollment contains Map Rendering Service (MRS), then you do *not* need to complete the type mapping process to enable Gotham integration. You can [create new ontology objects from](https://www.palantir.com/docs/foundry/object-link-types/create-ontology-objects-from-gaia/) or [add existing objects to](https://www.palantir.com/docs/foundry/geospatial/add-ontology-data-to-gaia/) Gotham without additional configuration. Follow the instructions below to check if your enrollment contains MRS.  
如果您的注册服务中包含地图渲染服务（MRS），那么您无需进行类型映射操作即可实现 Gotham 的集成。您可以无需任何额外配置就从 Gotham 中创建新的本体对象，或者添加现有的对象到 Gotham 中。请按照以下说明来检查您的注册服务是否包含 MRS。  
  
Contact Palantir Support with questions about MRS availability, installation, or its additional documentation present in Gotham.  
如有关于 MRS 的可用性、安装方式以及其在 Gotham 中附加文档的相关问题，请联系 Palantir 的支持部门。

## Use type mapping to create a unified representation of your ontology使用类型映射来创建你的本体概念的统一表示形式。

Type mapping enables a unified representation of your ontology across Foundry and Gotham that you manage within Foundry's [Ontology Manager](https://www.palantir.com/docs/foundry/ontology-manager/overview/) application. You can create new Gotham types based on existing Foundry object types, property types, and shared property types which remain synchronized as your ontology evolves over time. After completing the type mapping process, Gotham will be able to query Foundry object types and their metadata through the [Object Set Service](https://www.palantir.com/docs/foundry/object-backend/overview/#object-set-service-oss) - a Foundry backend service which supports object data searching, filtering, aggregating, and loading.  
类型映射功能使得你可以在 Foundry 和 Gotham 这两个系统中统一表示你的本体。你可以通过 Foundry 的本体管理器应用程序来创建新的 Gotham 类型。这些新类型可以基于现有的 Foundry 对象类型、属性类型以及共享属性类型来创建，随着本体内容的不断演变，这些类型会保持同步更新。完成类型映射后，Gotham 就可以通过 Object Set 服务来查询 Foundry 对象类型及其元数据了——这是 Foundry 提供的一个后端服务，支持对对象数据的搜索、过滤、汇总和加载操作。

Note 注意：

Type mapping is only available for enrollments using both Foundry and Gotham and must be enabled by a platform administrator before use. Once enabled for a Foundry Ontology, type mapping cannot be disabled. Only one Foundry Ontology per Gotham install can have type mapping enabled. Contact Palantir Support for assistance with type mapping enablement.  
类型映射仅适用于使用 Foundry 和 Gotham 进行注册的情况。使用之前，必须由平台管理员启用此功能。一旦为某个 Foundry Ontology 启用了类型映射功能，就无法再次禁用它。每个 Gotham 安装中，只能有一个 Foundry Ontology 启用了类型映射功能。如果您需要帮助来启用类型映射功能，请联系 Palantir 的支持部门。

### When to type map object types in your ontology何时在本体中输入映射对象类型？

[Follow the instructions below](#toggle-on-type-mapping-in-foundrys-ontology-manager) and type map object types in Ontology Manager if your enrollment does not [contain MRS](#how-to-check-if-your-enrollment-contains-mrs) and any of the conditions below are true:  
按照以下指示操作，如果您的注册信息中不包含 MRS，并且满足以下任一条件，请在 Ontology Manager 中输入“map object types”：

- You plan to use custom symbology that is not present as a [tactical graphic](https://www.palantir.com/docs/foundry/object-link-types/create-ontology-objects-from-gaia/#configure-a-tactical-graphic-on-your-gaia-map-and-tag-it-to-an-object-type) or [MIL-STD 2525 symbol](https://www.palantir.com/docs/defense-osdk/api/common/interfaceTypes/com-palantir-ontology-defense-types-mil2525CSymbol/). [Blueprint ↗](https://blueprintjs.com/) symbols are supported with or without type mapping.  
	您打算使用自定义的标注方式，这种标注方式不是以战术图形或 MIL-STD 2525 标准符号的形式存在的。Blueprint ↗的符号可以支持带有类型映射的情况，也可以仅使用默认的符号。
- You plan to configure [search templates](https://www.palantir.com/docs/foundry/geospatial/add-ontology-data-to-gaia/#create-a-search-template), a [function-backed Enterprise Map Layer (EML)](https://www.palantir.com/docs/foundry/geospatial/add-ontology-data-to-gaia/#use-a-function-backed-enterprise-map-layer), or a [versioned object set-backed EML](https://www.palantir.com/docs/foundry/geospatial/add-ontology-data-to-gaia/#use-a-versioned-object-set-backed-enterprise-map-layer) to add data from your ontology to Gaia.  
	您打算配置搜索模板、基于功能的企业地图层（EML），或者基于版本化的对象集的 EML，以便将来自您本体数据添加到 Gaia 中。

## Toggle on type mapping in Foundry's Ontology Manager在 Foundry 的 Ontology Manager 中启用类型映射功能

To integrate data in your Foundry Ontology with Gotham, you will first need to toggle on type mapping for your object type of interest within Foundry's Ontology Manager by following the steps below:  
要将数据整合到你的 Foundry Ontology 中，并连接到 Gotham 系统，你需要按照以下步骤在 Foundry Ontology 管理器里启用相关对象类型的类型映射功能：

1. Launch Ontology Manager from your home screen.  
	从主屏幕启动 Ontology Manager 应用程序。
2. Locate and select your object type to type map.  
	找到并选择你想要操作的对象类型，然后输入相应的映射信息。
3. Select **Capabilities** within the object type's left-hand panel.  
	在对象类型的左侧面板中选择功能选项。
4. Scroll down to the **Gotham Integration** panel and toggle on `Allow objects of this type to be accessed from Gotham applications`.  
	请向下滚动到“Gotham 集成”面板，然后启用 `Allow objects of this type to be accessed from Gotham applications` 。

![A user can toggle on Gotham Integration for an Object Type from Foundry's Ontology Manager application.](https://www.palantir.com/docs/resources/foundry/object-link-types/enable-gotham-mapping.png)

Note 注意：

Type mapped objects must contain a `geopoint` property to display on a Gaia map. The property can be native to the object type's backing dataset(s) or derived from a latitude/longitude pair or `geopoint` using Pipeline Builder's [create Ontology geopoint](https://www.palantir.com/docs/foundry/pb-functions-expression/createOntologyGeopointV1/) transform feature.  
在 Gaia 地图中显示时，类型映射的对象必须包含一个 `geopoint` 属性。该属性可以是对象类型本身所依赖的数据集中的属性，也可以通过 Pipeline Builder 的 createOntology geopoint transform 功能从经纬度对或 `geopoint` 中派生出来。

## Configure an object type's parent category and Gotham property types配置对象类型的父类别以及 Gotham 属性类型。

Once you toggle on **Gotham Integration**, you can follow the steps below to create a new Gotham object type derived from an existing Foundry object type, specify the object type's **Parent category**, and configure its **Property types**:  
一旦您启用了 Gotham 集成功能，就可以按照以下步骤创建一个新的 Gotham 对象类型。该类型是从现有的 Foundry 对象类型派生而来的。您需要指定该对象类型的父类别，并配置其属性类型。

1. Select **Create a new object type** within the **Object type** section of **Gotham Integration** to create a new object type in Gotham from an existing Foundry object type.  
	在 Gotham Integration 的“对象类型”部分中，选择“创建新的对象类型”，从而从现有的 Foundry 对象类型中创建一个新的对象类型。
2. Identify the **Parent category** of the new object type in Gotham by selecting between `Entity` (such as a person, organization, or vehicle), `Event` (such as a flight, meeting, or concert), or `Document` (such as a PDF file, text document, or report) based on your use case.  
	通过选择 `Entity` （例如个人、组织或车辆）、 `Event` （例如航班、会议或音乐会）或 `Document` （例如 PDF 文件、文本文档或报告）来识别 Gotham 中新对象类型的父类别，具体取决于你的使用场景。
3. Use the **Property types** section to map Foundry object type properties to Gotham - a property can be shared or cloned into the Gotham ontology. You will see a blue `Mapped` tag next to the property's name once you complete that configuration on a given property.  
	请使用“属性类型”部分来将 Foundry 对象类型的属性映射到 Gotham 本体中。这种属性可以被共享或复制到 Gotham 本体中。当您完成某个属性的配置后，会在该属性的名称旁边看到蓝色的 `Mapped` 标签。
	- `Do not map property to Gotham` is the default option - Foundry properties you do not map will not propagate in the Gotham ontology.  
		`Do not map property to Gotham` 是默认选项——那些没有进行映射的工厂属性在 Gotham 本体中不会得到体现。
		- `Assign to shared property` enables you to select an *existing* shared property to map against.  
		`Assign to shared property` 允许你选择一个现有的共享属性来进行映射。
		- `Promote to shared property` creates a *new* shared property for use by other objects.  
		`Promote to shared property` 创建一个新的共享属性，供其他对象使用。
		- `Create a local clone of the property in Gotham` creates a duplicate of the selected property in Gotham that is compatible with its applications.  
		`Create a local clone of the property in Gotham` 会创建出一个与所选属性在 Gotham 中兼容的副本，该副本可以应用于相关场景。

Foundry automatically type maps all shared properties to make them available in Gotham.  
该引擎会自动为所有共享属性生成映射，使其能够在 Gotham 中使用。

4. Select the green **Save** button on the right side of the top ribbon of your screen and review.  
	在屏幕顶部栏的右侧，选择绿色的“保存”按钮，然后进行查看。
5. Review the changes made to your object type and select **Save to ontology**.  
	请检查对您的对象类型所做的更改，然后选择“保存至本体”。

![A user can create a new object type or take over an existing when integrating their Foundry and Gotham ontology using a Criteria panel which enables them to select the object type's parent category.](https://www.palantir.com/docs/resources/foundry/object-link-types/ontology-manager-gotham-integration-view.png)

After you save your changes to the Ontology, scroll back up to the **Gotham Integration** section of the **Capabilities** page of your object type. You will now see a `Gotham URI` assigned to the object type and be able to view the `Installation status` reported by Gotham.  
在将修改内容保存到 Ontology 之后，返回到对象类型的“能力”页面中的“Gotham 集成”部分。现在你会看到有一个 `Gotham URI` 分配给该对象类型，并且可以查看 Gotham 所报告的 `Installation status` 信息。

Foundry's Ontology Manager will display one of the following installation statuses:  
Foundry 的 Ontology 管理器会显示以下其中一种安装状态：

- `Ready to integrate`: An object type is ready for type mapping to enable Gotham integration.  
	`Ready to integrate` ：某个对象类型已经准备好进行类型映射，可以进行 Gotham 集成了。
- `Installation in progress`: The object type's installation process is underway.  
	`Installation in progress` ：该对象类型的安装过程正在进行中。
- `Installation complete`: The installation process is complete, so the object type is available for use in Gotham.  
	`Installation complete` ：安装过程已经完成，现在该对象类型可以在 Gotham 中使用了。
- `Installation failed: {failureMessage}`: The object type's installation failed at least once and will be retried on the next installation run. The `{failureMessage}` outlines the reason for failure. Common installation failures include:  
	`Installation failed: {failureMessage}` ：该对象的安装至少失败了一次，将在下一次安装时重新尝试。 `{failureMessage}` 中列出了失败的原因。常见的安装失败情况包括：
	- *Live reindex*: If there is a live reindex running on Gotham, the ontology cannot be updated. Instead of staging changes during this time, the installation will fail and rerun automatically once the live reindex finishes.  
		实时重新索引：如果 Gotham 上正在运行实时重新索引任务，那么本体将无法更新。在这段时间内，系统的安装会失败，之后重新索引任务完成后，安装才会再次尝试进行。
		- *Required types are not installed*: For an object type's successful installation, all related property installations - or mappings - must be completed, including shared property types.  
		所需的类型并未被安装：对于一个对象类型的成功安装，所有相关的属性安装或映射都必须完成，包括共享属性类型。
		- *Other ontology updates*: If there are ontology updates running concurrently, then the type mapper will not be able to update the ontology and will rerun automatically.  
		其他本体更新：如果同时有本体更新在运行，那么类型映射器将无法更新本体，系统会自动重新运行。

Once your object type's installation status reads `Installation complete`, you will be able to search for and use your object type in Gotham's applications.  
当你的对象类型的安装状态显示为 `Installation complete` 时，你就可以在 Gotham 的应用程序中搜索并使用该对象类型了。

To deprecate a type mapped object type in Gotham, you can delete the object type in Foundry's Ontology Manager. Once deleted in Foundry, the corresponding object type and its property types will not be accessible in Gotham or available to its applications.  
要弃用 Gotham 中某个映射到的对象类型，可以在 Foundry 的 Ontology Manager 中删除该对象类型。一旦在 Foundry 中删除，该对象类型及其相关属性类型将不再在 Gotham 中可用，也无法被应用程序使用。

Gotham models Foundry dataset security and markings, meaning that Foundry data made available in Gotham through type mapping carries over the same access controls and classification.  
Gotham 模型基于 Foundry 数据集的安全性和标记标准进行构建，这意味着通过类型映射在 Gotham 中呈现的 Foundry 数据仍然遵循相同的访问控制和分类规范。
